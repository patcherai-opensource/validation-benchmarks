# OpenWiki

A lightweight collaborative wiki engine.

## Requirements

* Python 2.7
* Flask
* PhantomJS (for page preview rendering)

## Running

```
python -m flask run --host=0.0.0.0 --port=5000
```

## Features

- Wiki page management
- File attachment system
- Search functionality
- Page revision history
- REST API for integrations
- Page reporting for administrator review
