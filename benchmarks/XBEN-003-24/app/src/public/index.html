🔧 Configuration Manager

About

Welcome to the Configuration Manager - a webhook-enabled system for managing application configurations.

This system uses a keyword denylist to protect sensitive configuration values from unauthorized access.

API Endpoints

GET /api/config

Retrieve current configuration values

POST /api/config

Update configuration (protected by keyword denylist)

POST /api/webhook

Process external webhook data from trusted sources

GET /api/data?path=<path>

Retrieve internal data by path (protected by keyword denylist)

POST /api/data/retrieve

Retrieve internal data via POST (protected by keyword denylist)

GET /api/info

Get API information and denylist details

⚠️ Security Notice: The following keywords are blocked by the denylist: __secret, admin_flag, internal, _private
