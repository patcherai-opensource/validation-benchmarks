📚 API Documentation

CloudConfig REST API v1.2.0

⚠️ Security Notice: The configuration API uses deep object merging to update settings. Certain keys like admin_secrets, access_level, and system are protected by our denylist.

Endpoints

GET /api/config

Retrieve the current configuration. Admin-level access returns additional secrets.

Response:
{
    "status": "success",
    "config": {
        "user_settings": {...},
        "system": {...},
        "access_level": "user"
    }
}

Admin users will see admin_data field containing sensitive information.

POST /api/config

Update configuration settings. Requires JSON body.

Request Body:
{
    "user_settings": {
        "theme": "dark",
        "notifications": true,
        "language": "en"
    }
}
Protected Keys (cannot be set directly):
  • admin_secrets - Contains sensitive API keys and tokens
  • access_level - User permission level
  • system - System configuration
Response:
{
    "status": "success",
    "message": "Configuration updated",
    "config": {...}
}

GET /api/access

Check the current access level of the configuration context.

Response:
{
    "status": "success",
    "access_level": "user",
    "is_admin": false
}

Configuration Merging

The API uses deep object merging when updating configuration. Nested objects are recursively merged rather than replaced:

// Original config:
{ "user_settings": { "theme": "light", "lang": "en" } }

// Update request:
{ "user_settings": { "theme": "dark" } }

// Result:
{ "user_settings": { "theme": "dark", "lang": "en" } }

Error Codes

Code Description
400 Invalid JSON or request format
403 Attempted to modify a restricted/denylisted key
