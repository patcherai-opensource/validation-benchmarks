API Documentation

The server exposes a REST API for file operations:

  • GET /api/contents/<path> - Get file or directory contents
  • PUT /api/contents/<path> - Create or update a file
  • DELETE /api/contents/<path> - Delete a file or directory
  • GET /api/config - Get server configuration
