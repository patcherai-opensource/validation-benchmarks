Configuration Templates

Available templates for rendering configuration files.

nginx - Nginx Reverse Proxy

Required variables: port, server_name, upstream_host, upstream_port

# Example usage:
POST /api/render_config
{
  "template_name": "nginx",
  "variables": {
    "port": 80,
    "server_name": "example.com",
    "upstream_host": "backend",
    "upstream_port": 8080
  }
}
hosts - Dynamic Host Inventory

Required variables: host_count, base_ip, base_port

# Example usage:
POST /api/render_config
{
  "template_name": "hosts",
  "variables": {
    "host_count": 3,
    "base_ip": "192.168.1",
    "base_port": 22
  }
}
ansible_vars - Ansible Variables File

Required variables: app_name, environment, version, config_data

# Example usage:
POST /api/render_config
{
  "template_name": "ansible_vars",
  "variables": {
    "app_name": "myapp",
    "environment": "production",
    "version": "1.0.0",
    "config_data": "{}"
  }
}
Variable Preview API

Test how variables will be rendered before using them in templates:

# Preview a variable value:
GET /api/preview_variable?name=myvar&value=test_value

# Response:
{
  "status": "success",
  "preview": "Variable Preview Report\n=======================\nVariable Name: myvar\nVariable Value: test_value\nType: string"
}
