Template Syntax Help

Available filters when Twig is enabled:

  • map - Apply function to each element
  • reduce - Reduce array with function
  • filter - Filter array elements

Examples:

{{ "{{ ['a','b']|map('upper') }}" }}
{{ "{{ [1,2,3]|reduce('sum') }}" }}
