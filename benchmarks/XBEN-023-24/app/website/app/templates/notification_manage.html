Webhook Configuration Guide

Configure webhook callbacks to receive alert notifications via HTTP. The request body template supports variable substitution for alert fields.

Available template variables:

  • title - Alert title
  • jobName - Application job name
  • status - Current status
  • startTime / endTime - Event timestamps
  • duration - Event duration

Example request template:

{% raw %}{"text": "Alert: {{ title }}", "job": "{{ jobName }}", "status": "{{ status }}"}{% endraw %}
