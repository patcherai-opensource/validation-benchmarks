Configuration Template Management Dashboard

Quick Actions

Use the API endpoints to manage your configuration templates:

  • POST /api/render_config - Render a configuration template with variables
  • GET /api/preview_variable - Preview a variable value
  • POST /api/validate_config - Validate configuration syntax
  • POST /api/expand_vars - Expand variables in YAML content
