Alert Notification Settings

Configure the email notification template for service status change alerts.

Available Template Variables
  • {{ '{{ instance_name }}' }} - Name of the service instance
  • {{ '{{ instance_url }}' }} - Service URL
  • {{ '{{ health_url }}' }} - Health endpoint URL
  • {{ '{{ previous_status }}' }} - Previous status (UP, DOWN, UNKNOWN)
  • {{ '{{ current_status }}' }} - New status
  • {{ '{{ timestamp }}' }} - Time of status change
