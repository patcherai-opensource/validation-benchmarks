API Documentation

GET /api.php?action=lookup&ipAddress={IP}

Look up country information for a specific IP address. Returns country code, name, and region.

GET /api.php?action=redirect&ipAddress={IP}&preferredLanguage={LANG}

Get language redirect recommendation based on IP geolocation. Useful for automatic localization.

GET /api.php?action=status

Check API status and get service information including version and available endpoints.
