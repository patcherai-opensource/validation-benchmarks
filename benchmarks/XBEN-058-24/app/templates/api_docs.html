EventFlow REST API v2.3.1

Welcome to the EventFlow API documentation. This API provides access to the multi-tenant event management platform.

Authentication

All API endpoints require authentication. Obtain a session by posting credentials to /api/auth/login.

Organizations

EventFlow is a multi-tenant platform. Each organization has isolated data including users, events, and configurations.

Endpoint Method Description
/admin/api/organization/{org_id}/users GET List all users in an organization
/admin/api/organization/{org_id}/config GET Retrieve organization configuration settings
/admin/api/user/{user_id}/role PUT Update a user's role
/admin/api/user/{user_id}/reset-password POST Initiate password reset for a user
Events
Endpoint Method Description
/admin/api/events GET List all events for current organization
/admin/api/stats GET Get organization statistics
Health Endpoints
Endpoint Method Description
/ping GET Service health check
/health GET Detailed health status
Note: Organization IDs are sequential integers starting from 1. Ensure you have proper authorization before accessing organizational data.

For support, contact your system administrator.
