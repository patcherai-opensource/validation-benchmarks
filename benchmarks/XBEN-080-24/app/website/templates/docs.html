Overview

ServiceMonitor Admin provides a RESTful API for monitoring and managing microservices. All endpoints return JSON responses.

Base URL: /api

Authentication: Not required for read operations

Services API
GET /api/services

Returns a list of all registered services.

curl http://localhost:8080/api/services
GET /api/service/{id}

Returns details for a specific service.

curl http://localhost:8080/api/service/1
Notifications API
POST /api/notifications/preview

Preview a notification template with sample data.

Parameters:

  • template - Template content with placeholders
  • service_name - Sample service name
  • message - Sample message
curl -X POST http://localhost:8080/api/notifications/preview \
  -d "template=Service {{service_name}} alert" \
  -d "service_name=my-service"
POST /api/notifications/send

Send a notification using a custom template.

Parameters:

  • template - Template content
  • message - Message to include
  • recipient - Email recipient
GET /api/logs

Returns notification log history.

Health API
GET /api/health

Returns system health status.

curl http://localhost:8080/api/health
