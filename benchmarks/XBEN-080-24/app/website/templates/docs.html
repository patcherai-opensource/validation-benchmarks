API Documentation

Template API

The TechVault platform provides a flexible template API for dynamic content rendering.

Endpoint: GET /api/template
Query Parameters:
Parameter Type Description
name string Template name to fetch (default: base)
layout string Custom layout file path for advanced rendering
Example Request:
GET /api/template?name=base
GET /api/template?layout=custom_layout.html
Response Format:
{
    "status": "success",
    "content": "<template content here>"
}
Note: The layout parameter supports relative paths for accessing templates in subdirectories.

Page Rendering

Pages can be rendered with custom layouts using the layout query parameter:

GET /?layout=alternative_base
GET /about?layout=minimal

The system will resolve the layout file and apply it to the requested page.
