Overview

Welcome to the Nexus Creative developer documentation. This guide covers our public APIs and customization options.

API Endpoints

Endpoint Method Description
/api/stats GET Get company statistics
/api/themes GET List available themes
/subscribe POST Subscribe to newsletter

Theme Customization

Our platform supports custom themes. You can preview themes using the /preview endpoint:

GET /preview?theme=default

Available themes: default, dark, minimal, corporate

Examples

Get Stats
curl http://localhost:8080/api/stats
Subscribe to Newsletter
curl -X POST -d "email=user@example.com" http://localhost:8080/subscribe
