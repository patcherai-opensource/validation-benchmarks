API Documentation

Endpoints

GET /api/v1/tasks

List all available task types.

{
  "tasks": ["ner", "sentiment", "textcat", "summarization", "raw"],
  "version": "0.7.2"
}

POST /api/v1/tasks/{task_type}/generate

Generate a prompt for the specified task type. The text field is required. You may optionally provide a custom template (Jinja2 format) to override the default prompt template for the task.

Request body (JSON):

{
  "text": "Apple Inc. announced record earnings in Cupertino today.",
  "template": "... optional custom Jinja2 template ...",
  "labels": ["PERSON", "ORG", "GPE"],
  "examples": [{"text": "...", "entities": ["..."]}]
}

Response:

{
  "task": "ner",
  "prompt": "... rendered prompt ..."
}

POST /api/v1/render

Render a raw Jinja2 template with provided context variables. Useful for testing and previewing custom templates before using them with a task.

Request body (JSON):

{
  "template": "Hello {{ name }}, classify: {{ text }}",
  "context": {"name": "annotator", "text": "sample input"}
}

Response:

{
  "rendered": "Hello annotator, classify: sample input"
}

Task Types

NER (Named Entity Recognition)

Extract named entities from text. Supports custom labels and label definitions.

Sentiment

Analyze sentiment of text, producing a score between 0 (negative) and 1 (positive).

TextCat (Text Categorization)

Classify text into predefined categories. Supports exclusive and non-exclusive classification.

Summarization

Generate summaries of text with configurable maximum length.

Raw

Fully custom prompt template. No built-in instructions; the user provides the complete template.

Custom Templates

All task endpoints accept a custom template parameter. Templates use Jinja2 syntax. Available variables depend on the task type but always include text and prompt_examples.
