REST API Endpoints

GET/api/content/

Returns a list of available content files in the content directory.

Response:

{"files": [{"name": "example.txt", "path": "/app/content/example.txt"}]}

GET/preview/

Preview the contents of a content file.

Parameters:

  • file - Full path to the content file

Example:

/preview/?file=/app/content/welcome.txt

Security Note: Only files within authorized content directories can be accessed.

GET/search/

Search for content files containing a specific term.

Parameters:

  • q - Search query string

Content Directory Structure

All content files should be placed in the designated content directory. The system enforces path-based access controls to prevent unauthorized file access.
