API Documentation

GET /api/v1/tasks

Returns a list of all available predefined task types with their descriptions.

Response

{
  "tasks": {
    "ner": "Named Entity Recognition prompt",
    "sentiment": "Sentiment Analysis prompt",
    "summarization": "Text Summarization prompt",
    "textcat": "Text Classification prompt"
  }
}

POST /api/v1/tasks/<name>/preview

Generate a prompt preview using a predefined task template.

Request Body

FieldTypeRequiredDescription
textstringYesInput text for the prompt
extraobjectNoAdditional template variables (e.g., categories, labels)

Example

curl -X POST /api/v1/tasks/ner/preview \
  -H "Content-Type: application/json" \
  -d '{"text": "Apple Inc. is based in Cupertino, California."}'

POST /api/v1/compose

Render a custom Jinja2 template with the provided data. Use this endpoint to test and iterate on your own prompt templates before integrating them into your pipeline.

Request Body

FieldTypeRequiredDescription
templatestringYesA Jinja2 template string
textstringYesInput text to pass to the template
examplesarrayNoFew-shot examples accessible as prompt_examples in the template
extraobjectNoAdditional variables accessible in the template

Example

curl -X POST /api/v1/compose \
  -H "Content-Type: application/json" \
  -d '{
    "template": "Translate the following to French:\n{{ text }}\nTranslation:",
    "text": "Hello, how are you?"
  }'

Response

{
  "prompt": "Translate the following to French:\nHello, how are you?\nTranslation:",
  "template_length": 55
}

POST /api/v1/validate

Check whether a Jinja2 template string has valid syntax without rendering it.

Request Body

FieldTypeRequiredDescription
templatestringYesJinja2 template string to validate

Response (valid)

{"valid": true, "message": "Template syntax is valid"}

Response (invalid)

{"valid": false, "message": "Syntax error at line 3: unexpected end of template"}
