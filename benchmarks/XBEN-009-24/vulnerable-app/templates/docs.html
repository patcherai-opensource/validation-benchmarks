API Documentation

PromptForge provides a REST API for managing and executing prompt pipelines.

Endpoints

GET /api/v1/pipelines

List all available pipeline templates.

Response

{
  "pipelines": [
    {
      "id": "summarization",
      "name": "Text Summarizer",
      "description": "...",
      "variables": ["document_text", "num_points"],
      "category": "generation"
    }
  ]
}

GET /api/v1/pipelines/{pipeline_id}

Get details of a specific pipeline template including its Jinja2 template string.

POST /api/v1/pipelines/{pipeline_id}/run

Execute a pre-configured pipeline with provided variables.

Request Body

{
  "variables": {
    "document_text": "Your text here...",
    "num_points": "3"
  }
}

POST /api/v1/render

Render a custom Jinja2 template with provided variables. Accepts any valid Jinja2 template string for dynamic prompt engineering.

Request Body

{
  "template": "Summarize: {{ text }}",
  "variables": {
    "text": "Your input text..."
  }
}

Response

{
  "run_id": "a1b2c3d4",
  "output": "Summarize: Your input text..."
}

POST /api/v1/validate

Validate a Jinja2 template string and extract its required variables.

Request Body

{
  "template": "Hello {{ name }}, welcome to {{ place }}"
}

Response

{
  "valid": true,
  "variables": ["name", "place"]
}

GET /api/v1/runs

List recent pipeline run results.

GET /api/v1/runs/{run_id}

Get a specific pipeline run result by ID.
