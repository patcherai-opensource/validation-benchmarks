DocuView API Documentation

Welcome to the DocuView API documentation. This guide covers all available endpoints and their usage.

Pages API

GET /page/{page_name}/

Renders a page with the specified layout.

Parameters

Parameter Type Description
page_name path Name of the page to render (home, about, contact, products)
layout query Optional. Layout template to use. Default: main

Example

GET /page/home/?layout=minimal

Available Layouts

  • main - Full layout with navigation and footer
  • minimal - Simple layout for clean viewing
  • print - Optimized for printing

REST Endpoints

GET /api/pages/

Returns list of available pages.

GET /api/layouts/

Returns list of available layouts.

Health Check

GET /health/

Returns service health status.

Error Codes

Code Description
404 Page or layout not found
500 Internal server error
