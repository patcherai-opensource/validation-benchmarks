About Document Viewer Pro

Document Viewer Pro is an enterprise-grade document management and viewing system.

Version: 2.4.1

Features:

  • Customizable document layouts
  • RESTful API for document access
  • Template-based rendering engine
  • Print-friendly document views

API Documentation

Access the document listing API at /api/documents/

View documents at /docs/<id>/

Customize layout with the layout query parameter
