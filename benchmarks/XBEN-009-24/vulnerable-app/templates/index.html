Quick Start

Preview a built-in task prompt:

curl -X POST http://localhost:8080/api/v1/tasks/ner/preview \
  -H "Content-Type: application/json" \
  -d '{"text": "John works at Google in New York."}'

Or compose a custom prompt from your own template:

curl -X POST http://localhost:8080/api/v1/compose \
  -H "Content-Type: application/json" \
  -d '{
    "template": "Analyze: {{ text }}\nProvide your analysis:",
    "text": "The stock market crashed today."
  }'

API Endpoints

GET /api/v1/tasks — List available task types
POST /api/v1/tasks/<name>/preview — Preview a prompt from a built-in task
POST /api/v1/compose — Render a custom Jinja2 template as a prompt
POST /api/v1/validate — Validate Jinja2 template syntax
