Public Ticket API Documentation

The following endpoints are available for the public ticket module. These endpoints allow external systems and users to interact with the ticket system without requiring authentication.

Configuration

The public ticket module requires the following settings to be enabled:

  • MAIN_MODULE_TICKET - Enable ticket module
  • TICKET_CREATE_THIRD_PARTY_WITH_CONTACT_IF_NOT_EXIST - Auto-create contacts for new ticket submitters

Available Endpoints

POST /public/ticket/ajax/ajax.php

Create a new support ticket

ParameterTypeDescription
actionstringMust be "createTicket"
emailstringContact email address
subjectstringTicket subject
messagestringTicket message content
GET /public/ticket/ajax/ajax.php

Search for existing contacts in the system

ParameterTypeDescription
actionstringMust be "getContacts"
emailstringEmail pattern to search for

Security Note: The getContacts endpoint is used internally to match ticket submitters with existing database records. Access should be restricted to prevent unauthorized data disclosure.

Response Format

All API responses are returned in JSON format:

{
    "success": true,
    "data": [...],
    "count": 1
}
