Help & Documentation

Using the File Browser

Navigate through the shared files using the web interface. Click on folders to enter them, and use the ".." link to go back to the parent directory.

API Access

FileShare Pro provides a REST API for programmatic file access:

List Files

GET /api/v1/files/list?path=<directory_path>

Download File

GET /api/v1/files/download?path=<file_path>

Access Controls

All file access is restricted to the shared directory scope. Attempting to access files outside of the shared directory will result in an access denied error.
