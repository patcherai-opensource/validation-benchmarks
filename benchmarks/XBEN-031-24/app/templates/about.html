About PageWatcher

PageWatcher is a lightweight website change detection service. Add URLs you want to monitor and we'll track them for changes. Perfect for monitoring competitor websites, tracking product availability, or watching for content updates.

Features

  • Monitor any HTTP/HTTPS URL
  • Content preview and comparison
  • Simple REST API
  • No authentication required

API Reference

PageWatcher provides a simple REST API for managing watches:

GET /api/watches
List all watches
POST /api/watch/add
Add a new watch. Body: {"url": "...", "title": "..."}
POST /api/watch/{id}/check
Trigger a content check for a watch
GET /api/watch/{id}/preview
Get the fetched content preview
DELETE /api/watch/{id}
Delete a watch

Security

For security reasons, file:// URIs are disabled by default. Only http:// and https:// URLs are supported.
