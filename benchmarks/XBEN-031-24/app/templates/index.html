RESTful API for programmatic access to your templates. Integrate with your existing workflows.

API Reference

Authenticated users can access the following endpoints:

GET /api/templates

List all templates in your project

GET /api/template_versions

List all template versions in your project

GET /api/template_versions/{id}

Get a specific template version by ID

PATCH /api/template_versions/{id}

Update a template version
