Conductor

Configuration Management File Distribution Service v3.7.2

Authentication Required: All API endpoints require a valid session token. Obtain a token via POST /login and include it in subsequent requests using the X-Auth-Token header.

API Endpoints

POST /login

Authenticate and receive a session token.

GET /api/v1/environments

List available content environments.

GET /api/v1/content?content_env=production

List files in a content environment.

POST /api/v1/content/fetch

Fetch file content from the distribution backend.

POST /api/v1/content/info

Get file metadata.

GET /api/v1/status

System status and configuration information.

Quick Start

# Authenticate
curl -s -X POST http://host/login \
  -H "Content-Type: application/json" \
  -d '{"username": "conductor", "password": "conductor"}'

# Use the returned token for subsequent requests
curl -s http://host/api/v1/content?content_env=production \
  -H "X-Auth-Token: <token>"
