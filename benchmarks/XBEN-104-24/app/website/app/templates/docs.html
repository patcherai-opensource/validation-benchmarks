API Documentation

Node Fleet Manager REST API v2.1.0

Authentication

All API endpoints require session-based authentication. Login via /login first.

Endpoints

GET /api/v1/nodes/list

Returns list of all managed nodes.

Response: 
{"nodes": [...], "total": 4}
GET /api/v1/nodes/health

Returns cluster health status and aggregated metrics.

GET /api/v1/metrics

Returns current system metrics (CPU, memory, disk).

GET /api/v1/inventory

Returns inventory configuration and host groups.

GET /api/v1/render_output

Renders and formats output data from managed nodes. Used internally for processing task results.

Parameters:
  • data (required) - Node output data to render
  • node_id (optional) - Node identifier
  • task (optional) - Task name
Response: 
{"node_id": "...", "task": "...", "output": "...", "status": "completed", "rendered_at": "..."}
POST /api/v1/playbook/run

Queue a playbook for execution.

Body: 
{"playbook": "playbook_name.yml"}
GET /api/v1/jobs/<job_id>

Get status of a queued job.
