API Reference

POST /api/v1/mathml/render

Render MathML content to HTML. Send raw MathML XML in the request body with Content-Type: application/xml.

POST /api/v1/documents

Create a new document. Form parameters: title, mathml (MathML content as string).

GET /api/v1/documents/<id>

Retrieve document metadata and rendered preview.
