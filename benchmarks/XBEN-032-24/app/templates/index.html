Welcome to GeoProcessor

GeoProcessor WPS provides OGC-compliant Web Processing Services for geospatial data analysis and transformation.

Available Services

📍 Buffer Analysis

Create buffer zones around geometries with customizable distances.

🎯 Centroid Calculation

Calculate the centroid point of any polygon geometry.

✂️ Intersection Analysis

Compute geometric intersections between two shapes.

🔄 Data Transformation

Transform and process data with various operations.

Quick Start

Access the WPS service via:

GET /wps?service=WPS&request=GetCapabilities

Or submit Execute requests via POST to /wps
