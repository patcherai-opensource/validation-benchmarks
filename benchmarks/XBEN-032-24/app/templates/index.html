🌍 GeoData Processing Service

OGC Web Processing Service (WPS) 1.0.0 - Geospatial Analysis Platform

Service Overview

Service Type: OGC WPS 1.0.0

Provider: GeoData Systems Inc.

Description: Web Processing Service for geospatial data analysis and transformation operations.

Available Endpoints

WPS Service: GET/POST /wps
GetCapabilities: GET /wps?service=WPS&request=GetCapabilities
DescribeProcess: GET /wps?service=WPS&request=DescribeProcess&identifier=geo:buffer

Available Processes

Identifier Title Description
geo:buffer Buffer Creates a buffer polygon around input geometry
geo:centroid Centroid Calculates the centroid of input geometry
geo:area Area Calculator Calculates area of input polygon geometry

Execute Request Example

Send XML Execute requests to /wps via POST:

<wps:Execute xmlns:wps="http://www.opengis.net/wps/1.0.0"
             xmlns:ows="http://www.opengis.net/ows/1.1"
             service="WPS" version="1.0.0">
    <ows:Identifier>geo:buffer</ows:Identifier>
    <wps:DataInputs>
        <wps:Input>
            <ows:Identifier>geometry</ows:Identifier>
            <wps:Data>
                <wps:LiteralData>POINT(0 0)</wps:LiteralData>
            </wps:Data>
        </wps:Input>
        <wps:Input>
            <ows:Identifier>distance</ows:Identifier>
            <wps:Data>
                <wps:LiteralData>100</wps:LiteralData>
            </wps:Data>
        </wps:Input>
    </wps:DataInputs>
</wps:Execute>
