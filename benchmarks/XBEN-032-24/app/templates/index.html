PyWPS Test Server

Web Processing Service for geospatial data processing

Service Endpoints

  • WPS Service: /wps

Available Operations

  • GetCapabilities - List available processes
  • DescribeProcess - Get process details
  • Execute - Run a process (POST only)

Available Processes

  • echo - A simple process that echoes back the input data
  • buffer - Creates a buffer around a geometry

Example Execute Request

Send a POST request to /wps with an XML body:

<wps:Execute xmlns:wps="http://www.opengis.net/wps/1.0.0" 
             xmlns:ows="http://www.opengis.net/ows/1.1"
             version="1.0.0">
    <ows:Identifier>echo</ows:Identifier>
    <wps:DataInputs>
        <wps:Input>
            <ows:Identifier>inputdata</ows:Identifier>
            <wps:Data>
                <wps:LiteralData>Hello World</wps:LiteralData>
            </wps:Data>
        </wps:Input>
    </wps:DataInputs>
</wps:Execute>
