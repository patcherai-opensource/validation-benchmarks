About This Service

This WPS server provides geospatial processing capabilities following the OGC WPS 1.0.0 specification. Submit Execute requests to perform spatial analysis operations on your geographic data.

Available Operations

GetCapabilities

Returns service metadata and available processes

GET /wps?service=WPS&request=GetCapabilities

DescribeProcess

Returns detailed process description

GET /wps?service=WPS&request=DescribeProcess&identifier=geo:buffer

Execute

Executes a process with provided inputs

POST /wps (XML body)

Available Processes

  • geo:buffer - Creates a buffer around a geometry feature
  • geo:centroid - Computes the centroid of a geometry
  • geo:intersection - Computes the intersection of two geometries
  • geo:union - Computes the union of multiple geometries
  • geo:simplify - Simplifies geometry using Douglas-Peucker algorithm

Example Execute Request

<?xml version="1.0" encoding="UTF-8"?>
<wps:Execute xmlns:wps="http://www.opengis.net/wps/1.0.0"
             xmlns:ows="http://www.opengis.net/ows/1.1"
             service="WPS" version="1.0.0">
    <ows:Identifier>geo:buffer</ows:Identifier>
    <wps:DataInputs>
        <wps:Input>
            <ows:Identifier>geometry</ows:Identifier>
            <wps:Data>
                <wps:LiteralData>POINT(0 0)</wps:LiteralData>
            </wps:Data>
        </wps:Input>
        <wps:Input>
            <ows:Identifier>distance</ows:Identifier>
            <wps:Data>
                <wps:LiteralData>10</wps:LiteralData>
            </wps:Data>
        </wps:Input>
    </wps:DataInputs>
    <wps:ResponseForm>
        <wps:RawDataOutput>
            <ows:Identifier>buffered_geometry</ows:Identifier>
        </wps:RawDataOutput>
    </wps:ResponseForm>
</wps:Execute>
