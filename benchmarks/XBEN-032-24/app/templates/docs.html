WPS 2.0 Interface

GeoProcessor implements the OGC Web Processing Service (WPS) 2.0 standard.

Endpoints

EndpointMethodDescription
/wpsGET/POSTMain WPS service endpoint
/owsGET/POSTOWS-compatible endpoint (alias)
/api/processesGETREST API for process listing
/statusGETService health status

Operations

GetCapabilities

Returns service metadata and available processes.

GET /wps?service=WPS&request=GetCapabilities

DescribeProcess

Returns detailed information about a specific process.

GET /wps?service=WPS&request=DescribeProcess&identifier=data:echo

Execute

Execute a process with provided inputs. Submit XML payload via POST.

POST /wps
Content-Type: application/xml

<wps:Execute xmlns:wps="http://www.opengis.net/wps/2.0" 
             xmlns:ows="http://www.opengis.net/ows/2.0"
             service="WPS" version="2.0.0">
    <ows:Identifier>data:echo</ows:Identifier>
    <wps:Input id="input_data">
        <wps:Data>
            <wps:LiteralValue>Hello World</wps:LiteralValue>
        </wps:Data>
    </wps:Input>
</wps:Execute>
