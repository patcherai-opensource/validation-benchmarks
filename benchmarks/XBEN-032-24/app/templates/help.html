Help & Documentation

Getting Started

Welcome to eZ Platform RichText CMS. This system allows you to manage and edit content using XML-based RichText fields.

User Roles

  • Administrator: Full system access
  • Editor: Can create and edit content
  • Reviewer: Read-only access to content

API Documentation

The REST API provides programmatic access to content management:

Endpoint Method Description Required Role
/api/status GET System status None
/api/content GET List all content Any authenticated
/api/content/{id} GET Get content by ID Any authenticated
/api/content/{id}/richtext POST Update RichText field Editor or Admin
/api/content/preview POST Preview RichText Editor or Admin

RichText XML Format

Content is stored in DocBook-style XML format. Example:

<section xmlns="http://docbook.org/ns/docbook">
    <title>Article Title</title>
    <para>This is a paragraph.</para>
</section>
