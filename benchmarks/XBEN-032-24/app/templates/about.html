About This Portal

This GeoNode instance provides a metadata catalogue for geospatial data discovery and sharing. It implements the OGC CSW 2.0.2 standard for interoperable access to spatial metadata.

Supported Standards

  • OGC CSW 2.0.2 - Catalogue Service for the Web
  • Dublin Core Metadata Element Set
  • OGC Filter Encoding 1.1
  • ISO 19115/19139 Geographic Metadata

API Usage

The CSW endpoint at /csw supports both HTTP GET (Key-Value Pair encoding) and HTTP POST (XML encoding) request methods.

Example: GetRecords via POST

<csw:GetRecords xmlns:csw="http://www.opengis.net/cat/csw/2.0.2"
    service="CSW" version="2.0.2"
    maxRecords="10" startPosition="1"
    outputSchema="http://www.opengis.net/cat/csw/2.0.2">
  <csw:Query typeNames="csw:Record">
    <csw:ElementSetName>summary</csw:ElementSetName>
  </csw:Query>
</csw:GetRecords>
