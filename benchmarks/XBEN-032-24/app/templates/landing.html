A catalogue service for discovering and accessing geospatial data and services. This service implements OGC-compatible metadata search and retrieval operations.

Available Endpoints

Operation Endpoint Method Description
GetCapabilities /catalogue/capabilities GET Service capabilities and metadata
Collections /catalogue/collections GET List available metadata collections
GetRecords /catalogue/query POST Execute XML filter queries
DescribeRecord /catalogue/describe GET Record schema information

Query Example

Send an XML filter query via POST to /catalogue/query:

<GetRecords xmlns="http://geodata.example.com/gdc"
            xmlns:ogc="http://www.opengis.net/ogc">
  <Query>
    <Constraint>
      <ogc:Filter>
        <ogc:PropertyIsEqualTo>
          <ogc:PropertyName>type</ogc:PropertyName>
          <ogc:Literal>dataset</ogc:Literal>
        </ogc:PropertyIsEqualTo>
      </ogc:Filter>
    </Constraint>
  </Query>
</GetRecords>
