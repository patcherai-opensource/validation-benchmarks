API Documentation

WikiDocs provides a RESTful API for programmatic access to platform data.

LiveTable Results API
Endpoint
GET /wiki/bin/get/XWiki/LiveTableResults
Description

Returns data from wiki classes in JSON format. Used by LiveTable components for dynamic data display.

Parameters
Parameter Type Description
classname String The class to query (e.g., XWiki.WikiUsers)
collist String Comma-separated list of columns to return in results
outputSyntax String Output format (default: plain)
limit Integer Maximum number of results (default: 25, max: 100)
offset Integer Starting offset for pagination
Example Request
GET /wiki/bin/get/XWiki/LiveTableResults?classname=XWiki.WikiUsers&collist=id,username,display_name,email,role
Example Response
{
  "totalrows": 4,
  "returnedrows": 4,
  "offset": 0,
  "reqNo": 1,
  "rows": [
    {
      "doc_id": 1001,
      "id": 1001,
      "username": "admin",
      "display_name": "Administrator",
      "email": "admin@wiki.local",
      "role": "admin"
    },
    ...
  ]
}
Class Schema API
Endpoint
GET /wiki/bin/get/XWiki/ClassSheet
Description

Returns schema information about a wiki class, including available properties and their types.

Parameters
Parameter Type Description
classname String The class name to get schema for
Example Request
GET /wiki/bin/get/XWiki/ClassSheet?classname=XWiki.WikiUsers
Example Response
{
  "classname": "XWiki.WikiUsers",
  "properties": [
    {"name": "id", "type": "Number", "prettyName": "ID"},
    {"name": "username", "type": "String", "prettyName": "Username"},
    {"name": "display_name", "type": "String", "prettyName": "Display Name"},
    {"name": "email", "type": "Email", "prettyName": "Email"},
    {"name": "role", "type": "String", "prettyName": "Role"},
    {"name": "password", "type": "Password", "prettyName": "Password"}
  ]
}
Available Classes: XWiki.WikiUsers
