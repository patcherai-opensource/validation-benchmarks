Task Orchestrator
Dashboard API Docs

API Documentation

Task Orchestrator provides a REST API for executing system and automation commands.

Endpoints

GET /api/v1/health

Returns the health status of the service.

curl http://localhost:8080/api/v1/health

POST /api/v1/execute

Execute a task with the given command and arguments.

Request Body (JSON)
FieldTypeRequiredDescription
executable_cmdstringYesThe command to execute
cmdline_argslistNoList of arguments to pass to the command
runner_modestringNoExecution mode: "subprocess" (default) or "pexpect"
timeoutintegerNoTimeout in seconds (1-120, default 30)
Example
curl -X POST http://localhost:8080/api/v1/execute \
  -H "Content-Type: application/json" \
  -d '{"executable_cmd": "echo", "cmdline_args": ["hello", "world"]}'
Response
{
  "status": "successful",
  "rc": 0,
  "ident": "a1b2c3d4",
  "stdout": "hello world\n",
  "stderr": ""
}

GET /api/v1/tasks

List all completed tasks.

curl http://localhost:8080/api/v1/tasks

GET /api/v1/tasks/{ident}

Get details for a specific task.

curl http://localhost:8080/api/v1/tasks/a1b2c3d4
