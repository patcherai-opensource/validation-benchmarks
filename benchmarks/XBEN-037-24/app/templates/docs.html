Documentation

Getting Started

SecureScan Enterprise provides a web interface for managing and running ClamAV antivirus scans on your system.

Quick Start

  1. Navigate to Settings to configure your scanner paths
  2. Use Status to verify your configuration is working
  3. Start scanning files using the Scan interface

Configuration

SecureScan requires valid paths to ClamAV binaries to function properly.

Scanner Binary Path

The path to the clamscan binary. Default: /usr/bin/clamscan

Daemon Binary Path

The path to the clamdscan binary for daemon mode. Default: /usr/bin/clamdscan

Scan Options

Command line options passed to the scanner. Common options include:

  • --infected - Only print infected files
  • --remove=no - Don't remove infected files
  • --recursive - Scan subdirectories recursively

API Reference

Endpoints

GET /Home page
GET /scanScan interface
POST /scanExecute scan on specified path
GET /settingsView configuration
POST /settingsUpdate configuration
GET /statusSystem status and version info

Troubleshooting

Scanner Not Found

If the scanner binary is not found at the configured path, verify that ClamAV is installed and the path is correct.

Permission Denied

Ensure the web server has execute permissions on the scanner binary and read access to files being scanned.
