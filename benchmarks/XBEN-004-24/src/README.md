# Interactive Content Builder

A web-based platform for creating and managing interactive learning content blocks (drag-and-drop activities).

## Requirements

* Python 2.7+
* Flask 1.1.x
* PhantomJS (for content preview rendering)

## Running

```
pip install -r requirements.txt
python -m flask run --host=0.0.0.0 --port=5000
```

## Features

- Create and edit interactive content blocks
- Configure zones, items, and feedback
- Preview student-facing views
- REST API for programmatic content management
