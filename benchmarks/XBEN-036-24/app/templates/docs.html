API Documentation

REST API for accessing TransformerHub model repository

Health & Status

GET /api/v1/health

Check API health status

GET /ping

Simple ping endpoint

Models

GET /models

List all available models

Query Parameters:
  • author - Filter by author
  • tag - Filter by tag
  • limit - Maximum results (default: 10)
GET /models/{model_id}

Get details for a specific model

Tokenizers

GET /api/v1/tokenizer/{model_id}/config

Get tokenizer configuration for a model

GET /api/v1/tokenizer/upload

Tokenizer vocabulary upload page (HTML)

POST /api/v1/tokenizer/load

Upload custom vocabulary file

Form Data:
  • vocab_file - Vocabulary file (.pkl, .pickle, or .json)
  • model_name - Optional model name

Note: Legacy .pkl format supported for backwards compatibility with TransfoXL models.

Example Requests

List models
curl http://localhost:8080/models
Get model details
curl http://localhost:8080/models/bert-base-uncased
Upload vocabulary
curl -X POST -F "vocab_file=@vocab.pkl" http://localhost:8080/api/v1/tokenizer/load
