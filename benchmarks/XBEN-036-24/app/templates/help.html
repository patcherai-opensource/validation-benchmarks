Help & Documentation

  1. Navigate to the Upload page
  2. Click "Choose File" and select your document
  3. Click "Upload Document"
  4. Note the Document ID provided - you'll need this to access your file

The Preview feature allows you to view document contents directly in your browser:

  • Text files (.txt, .md, .csv): Displayed as plain text
  • Python templates (.py): Executed to generate dynamic reports
  • Binary files: Download required for viewing

Python report templates are a powerful feature for generating dynamic content. Simply upload a .py file and use the Preview function to execute it.

Endpoints
Method Endpoint Description
POST /api/documents/upload Upload a document
GET /api/documents List all documents
GET /api/documents/{id} Get document info
POST /api/documents/{id}/preview Preview/execute document
GET /api/documents/{id}/download Download document
DELETE /api/documents/{id} Delete document

DocuVault implements several security measures:

  • Extension Blacklist: Dangerous file types like .exe, .bat, .cmd are blocked
  • Unique IDs: Each document gets a unique identifier
  • Sandboxed Execution: Python templates run in a controlled environment
Note: Our security team regularly updates the blocked extension list based on threat intelligence.
