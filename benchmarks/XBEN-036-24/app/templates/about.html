About TransformerHub

TransformerHub is a community-driven repository for sharing pre-trained transformer models and tokenizers.

Features

  • Browse and download pre-trained models
  • Upload custom tokenizer vocabularies
  • REST API for programmatic access
  • Support for legacy model formats

Supported Formats

We support various model and tokenizer formats including:

  • PyTorch model checkpoints (.pt, .bin)
  • Tokenizer vocabularies (.json, .pkl)
  • Configuration files (config.json)
Note: We maintain backwards compatibility with older TransfoXL vocabulary formats (.pkl) to support legacy models in the community.
