API Endpoints
Method Endpoint Description
GET /api/models List available models
POST /api/load_model Load a pretrained model's tokenizer
POST /api/upload_model Upload and load a custom model
GET /api/model_info/{model_name} Get model details
GET /result Check execution result
Security Notice: This service loads tokenizer vocabulary files using pickle deserialization. Only upload models from trusted sources.
