Centralized metadata management and lineage tracking for your data ecosystem

GET/api/v1/system/config

POST/api/v1/users/login

GET/api/v1/users

PUT/api/v1/events/subscriptions

Features

  • 📊 Table and database metadata management
  • 🔔 Event-driven subscription system
  • 🔐 Token-based authentication
  • 🔍 Advanced filtering with expression language
  • 📈 Data lineage and impact analysis

Authentication

Most endpoints require authentication. Use /api/v1/users/login to obtain a Bearer token.

Example:

curl -X POST http://localhost:8080/api/v1/users/login \
  -H "Content-Type: application/json" \
  -d '{"email": "user@dataplatform.local", "password": "yourpassword"}'
