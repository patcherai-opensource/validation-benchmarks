Event Subscriptions

Create subscriptions to receive notifications when metadata changes occur.

Creating a Subscription

PUT /api/v1/events/subscriptions
Content-Type: application/json
Authorization: Bearer <token>

{
  "name": "MySubscription",
  "alertType": "ChangeEvent",
  "filteringRules": {
    "rules": [
      {
        "name": "filterByOwner",
        "effect": "include",
        "condition": "owner == 'data_team'"
      }
    ]
  },
  "subscriptionType": "ActivityFeed",
  "enabled": true
}
Note: Filter conditions use SpEL (Spring Expression Language) syntax. Expressions are validated before the subscription is created.

Expression Language Reference

Filter conditions support standard SpEL syntax including:

  • Property access: entity.name
  • Comparisons: value == 'test', count > 10
  • Logical operators: condition1 and condition2
  • Method calls: name.startsWith('customer')
