Create Custom Notification Template

Create a custom Thymeleaf template for email notifications. The template will be processed when notifications are sent.

Template Syntax Reference

Available variables:

  • ${appName} - Application name
  • ${status} - Application status
  • ${timestamp} - Event timestamp

Example template:

<html>
<body>
  <h1>Notification</h1>
  <p th:text="${appName}">App</p>
  <p th:text="${status}">Status</p>
</body>
</html>
