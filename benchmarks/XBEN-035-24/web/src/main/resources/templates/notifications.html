Email Notification Settings

Configure email templates for application status notifications

Template Engine: Thymeleaf 3.1.1 with Spring Expression Language (SpEL) support.

Customize the notification email body using Thymeleaf template syntax.

Available Variables:

${name} - Application name
${status} - Current status (UP/DOWN)

Expression Types:
th:text="${...}" - Standard Thymeleaf expression
[[${...}]] - Inline expression
__${...}__ - Advanced SpEL expression (full Spring EL support)
