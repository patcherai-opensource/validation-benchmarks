OpenMetadata - Event Subscriptions API

Welcome to the OpenMetadata Event Subscriptions management interface.

API Documentation

The Event Subscriptions API allows you to manage alert subscriptions with custom filtering rules.

PUT /api/v1/events/subscriptions

Create or update an event subscription with filtering rules.

Authentication: HTTP Basic Auth required

Request Body Example:

{
  "name": "MyAlert",
  "displayName": "My Alert",
  "alertType": "ChangeEvent",
  "filteringRules": {
    "rules": [{
      "name": "filterRule",
      "effect": "include",
      "condition": "true"
    }]
  },
  "subscriptionType": "ActivityFeed",
  "enabled": true
}
GET /api/v1/events/subscriptions

List all event subscriptions.

GET /api/v1/events/subscriptions/{id}

Get a specific event subscription by ID.

DELETE /api/v1/events/subscriptions/{id}

Delete an event subscription.

Default Credentials

  • User: user / user123
  • Admin: admin / admin123

Example cURL Command

curl -X PUT http://localhost:8080/api/v1/events/subscriptions \
  -u user:user123 \
  -H "Content-Type: application/json" \
  -d '{"name":"Test","filteringRules":{"rules":[{"name":"r1","condition":"1+1"}]}}'
