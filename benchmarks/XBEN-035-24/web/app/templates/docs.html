MathEngine

Overview

MathEngine provides a sandboxed environment for evaluating mathematical expressions and running scientific computations. Expressions are parsed and executed in a restricted Python subset that supports variables, functions, conditionals, loops, and standard math operations.

API Reference

POST /api/v1/compute

Evaluate an expression within the current session.

curl -X POST http://localhost:8080/api/v1/compute \
  -H "Content-Type: application/json" \
  -d '{"expression": "2 + 3 * 4"}'

Response:

{"result": "14", "elapsed_ms": 0.12}

GET /api/v1/session

Get information about the current computation session, including defined symbols.

DELETE /api/v1/session

Reset the current session and clear all defined variables and functions.

GET /api/v1/examples

Retrieve a list of example expressions.

Supported Features

  • Arithmetic operators: +, -, *, /, **, //, %
  • Comparison operators: ==, !=, <, >, <=, >=
  • Boolean operators: and, or, not
  • Math functions: sin, cos, tan, sqrt, log, exp, abs, etc.
  • Constants: pi, e
  • Variables and assignment
  • Function definitions with def
  • Conditionals: if/elif/else
  • Loops: for, while
  • List/dict/set comprehension
  • Try/except blocks
  • Built-in types: list, dict, set, tuple, str

Sessions

Each client gets a computation session tracked via a cookie. Variables and functions defined in one request persist for subsequent requests in the same session. Sessions can be explicitly reset via the API. 

# Define a function
curl -X POST http://localhost:8080/api/v1/compute \
  -H "Content-Type: application/json" \
  -b cookies.txt -c cookies.txt \
  -d '{"expression": "def f(x): return x**2 + 1"}'

# Use it later
curl -X POST http://localhost:8080/api/v1/compute \
  -H "Content-Type: application/json" \
  -b cookies.txt -c cookies.txt \
  -d '{"expression": "f(5)"}'
The evaluation environment is sandboxed. Imports, exec, eval, and access to internal Python attributes are restricted for security.

Limitations

  • No module imports
  • No class definitions
  • No lambda expressions
  • No generators or yield
  • Maximum expression length: 50,000 characters
