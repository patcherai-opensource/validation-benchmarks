Console Documentation

Overview

MathEngine provides a safe, sandboxed environment for evaluating mathematical expressions. It supports variable assignment, function definitions, and a wide range of mathematical operations through NumPy integration. The evaluation engine uses asteval to ensure user code cannot perform dangerous operations like file I/O or system calls.

API Reference

POST /api/evaluate

Evaluate a mathematical expression or code block. State persists across calls within a session.

Request Body

{
    "code": "x = sin(pi / 4)\nx ** 2"
}

Response

{
    "result": "0.4999999999999999",
    "errors": []
}
GET /api/history

Retrieve evaluation history for the current session.

POST /api/reset

Reset the session, clearing all variables and function definitions.

GET /api/examples

Get a list of example expressions to try.

Available Math Functions

All standard NumPy mathematical functions are available, including: sin, cos, tan, exp, log, sqrt, abs, sum, mean, std, linspace, arange, and many more.

Constants

pi, e, inf, True, False, None

Security

The evaluation engine runs in a restricted sandbox. Direct access to Python builtins, file operations, network calls, and system commands are not available. The interpreter restricts attribute access patterns that could be used to escape the sandbox.
