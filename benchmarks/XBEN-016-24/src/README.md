# LibreNMS Network Monitoring System

A network monitoring solution for managing network devices, sensors, and alerts.

## Features

- Device monitoring and management
- Health sensors (CPU, Memory, Storage, Temperature)
- Wireless sensors (WiFi RSSI, SNR, LTE metrics)
- Alert management
- Multi-user authentication

## Requirements

- Python 2.7
- Flask
- PhantomJS

## Running

```bash
docker-compose up
```

The service will be available on port 5000.
