# WsgiDAV File Server

A WebDAV-compatible file server with directory browsing enabled.

## Requirements

* Python 2.7
* Flask
* PhantomJS (for server-side rendering)

## Usage

```
pip install -r requirements.txt
python -m flask run --host=0.0.0.0 --port=5000
```

## Features

* Directory browsing with file listing
* WebDAV-compatible interface
* User authentication support
* Issue reporting system
