SecurePortal Documentation

Overview

SecurePortal is an enterprise access management system providing secure authentication and authorization services.

Authentication

The system supports standard username/password authentication with optional persistent "Remember Me" functionality.

Remember Me Feature

When enabled, the system creates a persistent authentication token stored in a secure cookie. This allows users to remain authenticated across browser sessions.

The remember-me cookie uses an industry-standard format with the following components:

  • User Class: The fully qualified class name of the user entity
  • User Identifier: The username
  • Expiry: Token expiration timestamp
  • Series: Unique identifier for the token series
  • Token: Random token value for authentication

Format: base64(UserClass:Username:Expiry:Series:Token)

Security Notes

The authentication system implements token rotation for remember-me cookies to prevent token replay attacks. Each time a remember-me token is used, a new token is generated and the old one is invalidated.
