API Usage Examples

Learn how to use the PromptForge API effectively.

1. List Available Templates
curl -X GET "http://localhost:8080/api/v1/templates"
2. Get Template Details
curl -X GET "http://localhost:8080/api/v1/templates/sentiment"
3. Generate Prompt with Built-in Template
curl -X POST "http://localhost:8080/api/v1/generate?template_id=sentiment" \
  -d 'variables={"text": "This movie was amazing!"}'
4. Custom Template with Variables

The /api/v1/raw endpoint supports full Jinja2 template syntax for advanced use cases:

curl -X POST "http://localhost:8080/api/v1/raw" \
  -H "Content-Type: application/json" \
  -d '{
    "template": "Summarize the following {{ doc_type }}: {{ content }}",
    "variables": {
      "doc_type": "article",
      "content": "Natural language processing has evolved significantly..."
    }
  }'
5. Template with Conditionals
curl -X POST "http://localhost:8080/api/v1/raw" \
  -H "Content-Type: application/json" \
  -d '{
    "template": "{% if formal %}Dear Sir/Madam,{% else %}Hey!{% endif %} Process: {{ task }}",
    "variables": {"formal": true, "task": "analyze sentiment"}
  }'
6. Template with Loops
curl -X POST "http://localhost:8080/api/v1/raw" \
  -H "Content-Type: application/json" \
  -d '{
    "template": "Extract entities from: {% for item in items %}{{ item }} {% endfor %}",
    "variables": {"items": ["Apple Inc.", "New York", "John Smith"]}
  }'
7. Check Service Health
curl -X GET "http://localhost:8080/api/v1/health"
8. View API Statistics
curl -X GET "http://localhost:8080/api/v1/stats"
Note: The built-in templates use a sandboxed environment for security. Custom templates via /api/v1/raw support the full Jinja2 feature set for maximum flexibility in prompt engineering workflows.
