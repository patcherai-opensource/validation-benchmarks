API Usage

The media browser accepts a node parameter containing a base64-encoded path.

Example: To browse a subdirectory named "images", encode the path and pass it:

GET /admin/media?node=aW1hZ2Vz

To download a file:

GET /admin/media/download?node=<base64_encoded_filepath>
