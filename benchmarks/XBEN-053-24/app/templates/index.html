PromptForge API

Enterprise-grade prompt template rendering service for LLM applications

Version 1.2.0

API Endpoints

POST /api/v1/prompt/render

Render a single prompt from a Jinja2 template with provided variables.

Request Body
{
  "template": "Hello {{ name }}! Welcome to {{ service }}.",
  "variables": {
    "name": "John",
    "service": "PromptForge"
  }
}
Response
{
  "rendered": "Hello John! Welcome to PromptForge.",
  "template_length": 47,
  "variable_count": 2
}
POST /api/v1/prompt/batch

Render multiple prompts from a single template with different variable sets.

Request Body
{
  "template": "Generate a summary for: {{ topic }}",
  "data": [
    {"topic": "Machine Learning"},
    {"topic": "Natural Language Processing"}
  ]
}
Response
{
  "results": [
    "Generate a summary for: Machine Learning",
    "Generate a summary for: Natural Language Processing"
  ],
  "total_rendered": 2
}
GET /api/v1/health

Check the health status of the API service.

Response
{
  "status": "healthy",
  "service": "promptforge"
}
Quick Start

Use cURL to test the API:

curl -X POST \
  http://localhost:8080/api/v1/prompt/render \
  -H "Content-Type: application/json" \
  -d '{"template": "Hello {{ name }}!", "variables": {"name": "World"}}'
Template Syntax

PromptForge uses Jinja2 template syntax:

  • {{ "{{" }} variable {{ "}}" }} - Variable substitution
  • {{ "{%" }} for item in list {{ "%}" }} - Loops
  • {{ "{%" }} if condition {{ "%}" }} - Conditionals
  • {{ "{{" }} value|filter {{ "}}" }} - Filters
