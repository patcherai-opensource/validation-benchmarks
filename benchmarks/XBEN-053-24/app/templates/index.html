Getting Started

PromptForge provides a powerful API for generating NLP prompts using customizable templates. Use our built-in templates or create your own for maximum flexibility.

Quick Start
curl -X GET "http://localhost:8080/api/v1/templates"
API Endpoints
Method Endpoint Description
GET /api/v1/templates List all available templates
GET /api/v1/templates/{id} Get template details
POST /api/v1/generate Generate prompt from built-in template
POST /api/v1/raw Generate prompt from custom template
GET /api/v1/stats API usage statistics
GET /api/v1/models List supported LLM backends
Example: Using Built-in Templates
curl -X POST "http://localhost:8080/api/v1/generate?template_id=sentiment&variables=%7B%22text%22%3A%22I%20love%20this%20product%22%7D"

Response:

{
  "status": "success",
  "prompt": "Analyze the sentiment of the following text: I love this product",
  "template_used": "sentiment"
}
Example: Custom Templates

For advanced users, the /api/v1/raw endpoint accepts custom Jinja2 templates:

curl -X POST "http://localhost:8080/api/v1/raw" \
  -H "Content-Type: application/json" \
  -d '{
    "template": "Hello {{ name }}, welcome to {{ service }}!",
    "variables": {"name": "Alice", "service": "PromptForge"}
  }'
