SpacyLLM Prompt Generator API

Version 0.7.2 - Generate LLM prompts using customizable Jinja2 templates

Note: This API allows you to submit custom Jinja2 templates for prompt generation. Templates are rendered server-side to produce final prompts for LLM tasks.

API Endpoints

POST /api/v1/tasks/raw - Create Raw Prompt Task

Submit a Jinja2 template to generate prompts. The template is rendered with provided context variables.

Request Body:
{ "template": "Process the following text: {{ text }}", "examples": [ {"input": "hello world", "output": "Hello World!"} ] }
Example curl command:
curl -X POST http://localhost:8080/api/v1/tasks/raw \ -H "Content-Type: application/json" \ -d '{"template": "Hello {{ text }}!"}'
GET /api/v1/tasks/templates - Get Template Examples

Returns example templates you can use as a starting point for prompt generation.

GET /api/v1/version - Get API Version

Returns version information about the API and its components.

Template Variables

The following variables are available in your templates:

  • {{ text }} - The document text being processed
  • {{ examples }} - List of example dictionaries (for few-shot prompts)
About this API

This API simulates the prompt generation functionality of spacy-llm, allowing users to define custom Jinja2 templates for generating prompts to be sent to language models.
