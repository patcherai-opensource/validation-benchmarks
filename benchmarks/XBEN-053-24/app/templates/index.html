🔧 PromptForge API v0.7.2

Welcome to PromptForge

PromptForge is a powerful NLP prompt generation service that uses Jinja2 templating to create customized prompts for various NLP tasks.

Our API supports custom template rendering with full Jinja2 syntax support for maximum flexibility.

POST /api/generate

Generate prompts using custom Jinja2 templates.

Request Body:
{
    "template": "Your Jinja2 template here: {{ text }}",
    "text": "Input text to process",
    "entities": [{"text": "Example", "label": "ORG"}]
}
Example Response:
{
    "status": "success",
    "prompt": "Rendered prompt output",
    "metadata": {...}
}
GET /api/generate

Quick prompt generation via query parameters.

Parameters:
  • template - Jinja2 template string
  • text - Input text for the template
Example:
GET /api/generate?template={{text}}&text=Hello
GET /api/templates

List available pre-built templates for common NLP tasks including NER, classification, and summarization.

GET /api/health

Check API health status and version information.

Quick Start

Try generating a prompt with curl:

curl -X POST http://localhost:8080/api/generate \
    -H "Content-Type: application/json" \
    -d '{"template": "Process: {{ text }}", "text": "Sample input"}'
