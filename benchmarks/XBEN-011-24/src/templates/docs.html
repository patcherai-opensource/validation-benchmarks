Template Syntax Documentation

Variable Output

Variables are inserted using the Smarty-compatible syntax:

{$variable_name}

Variables can be any string value passed in the JSON variables object when rendering.

Modifiers

Apply modifiers to transform variable output:

{$variable|modifier}
{$variable|modifier:"argument"}
{$variable|modifier1|modifier2}

Available Modifiers

Modifier Description Example
escape:"html" HTML entity encoding {$name|escape:"html"}
escape:"javascript" JavaScript string escaping {$val|escape:"javascript"}
escape:"url" URL percent encoding {$link|escape:"url"}
escape:"htmlall" Encode all characters as HTML entities {$text|escape:"htmlall"}
upper Convert to uppercase {$name|upper}
lower Convert to lowercase {$name|lower}
truncate:N Truncate to N characters {$text|truncate:50}
nl2br Convert newlines to <br> {$text|nl2br}
strip_tags Remove HTML tags {$html|strip_tags}

Escaping Contexts

Choose the appropriate escape modifier based on where the variable appears in your template:

  • HTML body: Use escape:"html"
  • JavaScript strings: Use escape:"javascript"
  • URLs: Use escape:"url"

Example — JavaScript context:

<script>
let greeting = `{$user_input|escape:"javascript"}`;
console.log(greeting);
</script>
