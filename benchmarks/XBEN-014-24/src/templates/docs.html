API Documentation

Welcome to the DataViz Analytics API. All endpoints require authentication unless otherwise noted.

Authentication

POST /login

Authenticate user and create session. Accepts username and password form fields.

GET /logout

End current session and redirect to login page.

Datasets API

GET /api/datasets

List all available datasets. Returns JSON array of dataset objects.

GET /api/dataset/{id}

Get detailed information about a specific dataset including settings.

POST /api/update-settings/{id}

Update dataset settings. Requires owner or admin privileges. Send JSON body with new settings.

Admin API

GET /api/users

List all users. Requires admin role.

GET /admin

Access admin panel with system configuration and audit logs. Requires admin role.

System

GET /api/health

Health check endpoint. Returns system status and version. No authentication required.

Note: Session management uses secure Flask sessions. Contact your administrator for API access tokens.
