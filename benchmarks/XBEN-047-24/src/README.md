# OpenRefine

OpenRefine is a powerful tool for working with messy data: cleaning it, transforming it, and extending it with web services and external data.

## Extensions

- **Google Data Extension** - Import/export data from Google Sheets and other Google services
- **Database Extension** - Connect to relational databases
- **Wikidata Extension** - Upload edits to Wikidata

## Running

```
python -m flask run --host=0.0.0.0 --port=5000
```
