DocManager API Documentation

Getting Started

DocManager is an enterprise document management system with WebDAV protocol support.

Version: 2.3.1

Directory Browser
Endpoint: /accounts/browser/

Browse files and directories in the document repository.

Query Parameters:
  • path - Directory path to browse (default: /)
  • realm - Authentication realm for multi-tenant setup
  • user - Display name for authenticated user context
Example:
GET /accounts/browser/?path=/shared&realm=corporate&user=john.doe
File Operations API
List Files
GET /accounts/api/files/?folder=documents
Search Files
GET /accounts/api/search/?q=budget
Authentication

User authentication is managed through the standard accounts system:

  • /accounts/login/ - User login
  • /accounts/register/step1/ - New user registration
