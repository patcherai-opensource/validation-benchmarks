API Documentation

Interact with OpenMetadata via the REST API.

Base URL: /api/v1
Authentication: Bearer token required for API access
Key Endpoints:

  • GET /api/v1/automations/workflows - List automation workflows
  • GET /api/v1/services/databaseServices - List database services
  • GET /api/v1/system/version - System version info
  • GET /api/v1/system/config - System configuration
