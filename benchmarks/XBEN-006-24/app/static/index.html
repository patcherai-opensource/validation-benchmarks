Dataset Management API

Manage your LLM evaluation datasets and prompts through our REST API.

API Endpoints

All endpoints require authentication via X-Api-Key header.

GET /api/v1/datasets

List all datasets in your project

GET /api/v1/datasets/{dataset_id}/prompts

List all prompts in a dataset

GET /api/v1/datasets/prompts/{id}

Get a specific prompt by ID

PATCH /api/v1/datasets/prompts/{id}

Update a prompt's messages

Body: {"messages": "new content"}
GET /api/v1/users/me

Get current user information

Quick Start

# Get your datasets
curl -H "X-Api-Key: your_api_key" http://localhost:8080/api/v1/datasets

# Get prompts in a dataset
curl -H "X-Api-Key: your_api_key" http://localhost:8080/api/v1/datasets/1/prompts

# Update a prompt
curl -X PATCH -H "X-Api-Key: your_api_key" \
     -H "Content-Type: application/json" \
     -d '{"messages": "updated content"}' \
     http://localhost:8080/api/v1/datasets/prompts/1
