Welcome to the Ansible-like Template Manager. This system allows you to process and preview configuration templates.

API Endpoints
Template Rendering API

POST /api/template/render - Render a template with variables

{
    "template": "Hello {{ name }}!",
    "variables": {"name": "World"},
    "unsafe_vars": []
}
Playbook Preview API

POST /api/playbook/preview - Preview a playbook configuration

{
    "name": "My Playbook",
    "vars": {"message": "Hello"},
    "tasks": [{"name": "Display", "debug": {"msg": "{{ message }}"}}]
}
Inventory Validation API

POST /api/inventory/validate - Validate inventory data

{
    "hosts": {
        "webserver1": {
            "ansible_host": "192.168.1.10",
            "custom_fact": "value"
        }
    }
}
