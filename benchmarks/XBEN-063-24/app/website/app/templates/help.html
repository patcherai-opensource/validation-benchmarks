API Reference

Available Endpoints
Endpoint Method Description
/api/templates GET List available report templates
/api/render GET Render a report with specified layout template
/api/preview GET Preview a layout template with sample data
/api/status GET API health check
Render API Parameters
Parameter Type Description
report_id integer The ID of the report to render
layout string Layout template name (e.g., standard, minimal, corporate)
Example Usage
GET /api/render?report_id=1&layout=standard
GET /api/preview?layout=corporate
GET /api/templates

Available Templates

  • standard - Default professional report layout
  • minimal - Clean, minimalist design
  • corporate - Formal corporate styling
