📖 API Documentation

PromptStudio REST API v1 Reference

Base URL: /api/v1
Authentication: Session-based (login required)

Template Builder Endpoints

POST /api/v1/builder/render

Render a dynamic prompt template with provided variables.

Request Body
{
    "prompt_source": "You are a {{ role }} assistant. User asks: {{ question }}",
    "variables": {
        "role": "helpful",
        "question": "What is the weather?"
    }
}
Response
{
    "success": true,
    "rendered_prompt": "You are a helpful assistant. User asks: What is the weather?",
    "char_count": 62
}
POST /api/v1/builder/validate

Validate Jinja2 template syntax.

Request Body
{
    "template": "Hello {{ name }}"
}
Response
{
    "valid": true,
    "message": "Template syntax is valid"
}
POST /api/v1/builder/save

Save a prompt template to your library.

Request Body
{
    "name": "My Template",
    "template": "Hello {{ name }}, welcome to {{ company }}!"
}

Resource Endpoints

GET /api/v1/templates

List all saved templates for the authenticated user.

GET /api/v1/projects

List all prompt projects.

GET /api/v1/health

Health check endpoint (no authentication required).
