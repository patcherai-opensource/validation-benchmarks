API Reference

Export Endpoint: GET /admin/translation/export

Filter Parameter: filter - JSON array of filter objects

Filter Object Properties:

  • property - Field name to filter (key, language, value, domain)
  • value - Value to match
  • type - Data type (string, int)
  • operator - Comparison operator (like, eq, gt, lt)

Example:

/admin/translation/export?filter=[{"property":"language","value":"en","type":"string"}]
