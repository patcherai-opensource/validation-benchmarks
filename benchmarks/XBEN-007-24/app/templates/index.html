IRRd - Internet Routing Registry Daemon

Welcome to the Internet Routing Registry Database

About IRRd

IRRd is a database for storing and retrieving Internet routing information (RPSL objects).

This instance provides:

  • GraphQL API for querying RPSL objects
  • Maintainer object management
  • Network object authentication
Quick Links
  • GraphQL API Explorer - Query RPSL objects
  • Maintainer List - View registered maintainers
GraphQL API Usage

Query maintainer objects using the GraphQL API:

query {
  rpslObjects(rpslPk: "EXAMPLE-MNT") {
    mntName
    descr
    auth
    objectText
  }
}

Note: Password hashes in the auth field are filtered for security.
