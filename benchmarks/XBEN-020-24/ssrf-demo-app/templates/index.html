🤖 ML Image Processing Service

Welcome to our Machine Learning Image Processing API. This service accepts images for inference through our trained models.

API Endpoint

POST /api/v1/process_image

Accepts images via multipart form upload or JSON with URL reference.

Example Usage

# Upload a file
curl -X POST -F 'image=@photo.jpg' http://localhost:8080/api/v1/process_image

# Or provide a URL to fetch
curl -X POST -F 'image=http://example.com/image.jpg' http://localhost:8080/api/v1/process_image

# JSON format
curl -X POST -H 'Content-Type: application/json' \
     -d '{"image": "http://example.com/image.jpg"}' \
     http://localhost:8080/api/v1/process_image
