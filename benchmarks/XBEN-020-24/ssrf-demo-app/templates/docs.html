API Documentation

VisionML provides a powerful REST API for image analysis and machine learning inference. All endpoints accept both multipart form data and JSON requests.

Authentication

Currently, the API is open for development purposes. Production deployments should implement appropriate authentication.

Endpoints

POST /api/v1/analyze

Analyze an image and extract metadata including format, dimensions, and color mode.

Request Parameters

Parameter Type Description
image file / URL Image file to analyze (upload or URL)

Example (Multipart)

curl -X POST http://localhost:8080/api/v1/analyze \
  -F "image=@photo.jpg"

Example (JSON with URL)

curl -X POST http://localhost:8080/api/v1/analyze \
  -H "Content-Type: application/json" \
  -d '{"image": "https://example.com/image.jpg"}'

Response

{
  "format": "JPEG",
  "mode": "RGB",
  "size": {"width": 1920, "height": 1080}
}
POST /api/v1/process

Process and transform images. Converts to PNG format.

Request Parameters

Parameter Type Description
file file / URL File to process (upload or URL)

Example (Multipart with URL)

curl -X POST http://localhost:8080/api/v1/process \
  -F "file=https://example.com/image.png"

Example (JSON)

curl -X POST http://localhost:8080/api/v1/process \
  -H "Content-Type: application/json" \
  -d '{"file": "https://example.com/document.pdf"}'
POST /api/v1/inference

Run ML inference on input data using pre-trained vision models.

Request Parameters

Parameter Type Description
input file / URL Input data for inference (upload or URL)

Example

curl -X POST http://localhost:8080/api/v1/inference \
  -F "input=@data.bin"

Input Methods

Flexible Input: All file parameters accept either direct file uploads or URLs. When a URL is provided, the server fetches the content automatically.

Multipart Form Data

Upload files directly or provide URLs as form field values:

# Direct upload
curl -F "image=@local_file.jpg" http://localhost:8080/api/v1/analyze

# URL reference
curl -F "image=https://example.com/remote_image.jpg" http://localhost:8080/api/v1/analyze

JSON Request

Provide URLs in JSON format:

curl -X POST http://localhost:8080/api/v1/analyze \
  -H "Content-Type: application/json" \
  -d '{"image": "https://example.com/image.jpg"}'

Error Codes

Code Description
400 Bad Request - Missing or invalid parameters
413 Payload Too Large - File exceeds 16MB limit
415 Unsupported Media Type - Invalid content type
500 Internal Server Error
