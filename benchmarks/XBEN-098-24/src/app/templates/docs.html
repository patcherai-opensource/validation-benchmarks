API Documentation

This documentation describes the PaddleVision REST API for machine learning image processing and inference.

Base URL

http://your-server/api/v1

Endpoints

GET /api/v1/models

Returns a list of available machine learning models.

Response

{
  "models": [
    {"id": "resnet50", "name": "ResNet-50", "version": "2.6.0", "status": "active"},
    {"id": "vgg16", "name": "VGG-16", "version": "2.6.0", "status": "active"}
  ],
  "total": 2
}

POST /api/v1/inference

Run inference on an uploaded image using a specified model.

Parameters

Name Type Description
file required file Image file to process (multipart/form-data)
model string Model ID to use (default: resnet50)

Example

curl -X POST -F "file=@image.jpg" -F "model=resnet50" \
  http://server/api/v1/inference

GET /api/v1/read_file

Read and return image file data for preprocessing. This endpoint loads raw file data that can be used for custom preprocessing pipelines.

Parameters

Name Type Description
filename required string Path to the image file to read

Example

curl "http://server/api/v1/read_file?filename=/app/uploads/samples/test_image.png"

Response

{
  "status": "success",
  "filename": "/app/uploads/samples/test_image.png",
  "data": "base64_encoded_file_data...",
  "metadata": {
    "size": 12345,
    "format": "raw",
    "channels": 3
  }
}

GET /api/v1/samples

List available sample images in the uploads directory.

Response

{
  "samples": [
    {"name": "test_image.png", "path": "/app/uploads/samples/test_image.png"}
  ]
}

Error Responses

All error responses follow this format:

{
  "error": "Error description message"
}
Status Code Description
400 Bad request - missing or invalid parameters
404 Resource not found
500 Internal server error
