# TplRender - Template Rendering Engine

A modern template rendering engine with JavaScript escaping for security.

## Features
- Template preview with variable substitution
- Safe rendering with JavaScript escaping
- REST API for programmatic access
- ES6 template literal support

## Endpoints
- `/` - Home page
- `/preview` - Template preview (POST with `value` parameter)
- `/render` - Safe render (POST with `message` parameter)
- `/docs` - Documentation
- `/api/v1/status` - API status
- `/api/v1/templates` - List templates
- `/api/v1/templates/{id}` - Template details
