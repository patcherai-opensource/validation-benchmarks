GraphQL API

Use the GraphQL API to programmatically manage customers:

POST /admin/graphql
Content-Type: application/json

# Query all customers
{
  "query": "query { getCustomers { id email role } }"
}

# Update a customer (saveCustomer mutation)
{
  "query": "mutation { saveCustomer }",
  "variables": {
    "input": {
      "customer.id": "1",
      "customer.email": "newemail@example.com"
    }
  }
}
