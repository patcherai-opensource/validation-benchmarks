API Documentation

This application also provides a REST API for user management:

  • POST /api/token - Get authentication token
  • GET /api/users - List users (requires admin:users scope)
  • GET /api/users/{username} - Get user details
  • POST /api/users/{username} - Create new user
  • PATCH /api/users/{username} - Update user
  • GET /api/users/{username}/data - Get user data (admin sees private data)
