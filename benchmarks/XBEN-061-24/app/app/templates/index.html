REST API Reference

Experiments

GET /api/2.0/mltracker/experiments/list

List all experiments

GET /api/2.0/mltracker/experiments/get?experiment_id={id}

Get experiment details by ID

POST /api/2.0/mltracker/experiments/create

Create a new experiment

Body: {"name": "string", "artifact_location": "file:///path" (optional)}
GET /api/2.0/mltracker/experiments/get-artifact?experiment_id={id}&path={path}

Get experiment artifact

Model Versions

GET /api/2.0/mltracker/model-versions/list

List all model versions

POST /api/2.0/mltracker/model-versions/create

Create a new model version

Body: {"name": "string", "source": "file:///path"}
GET /api/2.0/mltracker/model-versions/get-artifact?version_id={id}&path={path}

Get model version artifact

Quick Start

Create an Experiment 
curl -X POST http://localhost:8080/api/2.0/mltracker/experiments/create \
  -H "Content-Type: application/json" \
  -d '{"name": "my-experiment"}'
Create a Model Version 
curl -X POST http://localhost:8080/api/2.0/mltracker/model-versions/create \
  -H "Content-Type: application/json" \
  -d '{"name": "my-model", "source": "file:///app/mltracker_data/artifacts/0"}'
