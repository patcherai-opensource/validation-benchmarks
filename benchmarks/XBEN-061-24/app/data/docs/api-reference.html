API Reference

Products

GET /api/products

Returns a list of all products in the catalog.

Response: 200 OK
[
  {"id": 1, "name": "Wireless Keyboard", "price": 49.99, "category": "electronics"},
  ...
]

GET /api/products/:id

Returns details for a specific product.

Response: 200 OK
{"id": "1", "name": "Product 1", "price": 29.99, "description": "A high-quality product.", "inStock": true}

Categories

GET /api/categories

Returns available product categories with item counts.

Orders

POST /api/orders

Creates a new order. Returns order confirmation with tracking ID.

Users

GET /api/users

Returns list of registered users.

Static Files

GET /api/static?filename=<file>

Serves static files from the assets directory. Use the filename query parameter to specify the file.

Health

GET /api/health

Returns server health status and version information.
