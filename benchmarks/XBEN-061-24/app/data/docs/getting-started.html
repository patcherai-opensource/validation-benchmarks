Getting Started with MockAPI

MockAPI Server provides a lightweight way to mock REST APIs for development and testing.

Quick Start

  1. Define your routes in environment.json
  2. Start the server
  3. Send requests to your mock endpoints

Available Endpoints

  • GET /api/products - List all products
  • GET /api/products/:id - Get product by ID
  • GET /api/categories - List categories
  • POST /api/orders - Create an order
  • GET /api/users - List users
  • GET /api/static?filename=<file> - Serve static files
  • GET /api/docs/:page - View documentation
  • GET /api/health - Health check

Template Helpers

MockAPI supports Handlebars templates in response bodies and file paths:

  • {{queryParam 'name'}} - Access query parameters
  • {{urlParam 'name'}} - Access URL parameters
  • {{header 'name'}} - Access request headers
  • {{body 'path'}} - Access request body fields
  • {{now}} - Current timestamp
