Getting Started

DataFlow is an enterprise connection management platform designed for managing database connections, API credentials, and external service configurations.

Authentication

Access to the connection management interface requires authentication. Users are assigned roles that determine their level of access:

Role Permissions Description
viewer View connections (masked) Can view connection list and details with sensitive data masked
operator View + Edit connections Can view and edit all connection details
admin Full access Complete control over all platform settings

API Reference

GET /api/connections

Returns a list of all connections (requires authentication)

GET /api/health

Health check endpoint for monitoring

Connection Types

DataFlow supports multiple connection types:

  • PostgreSQL - For PostgreSQL database connections
  • MySQL - For MySQL/MariaDB databases
  • Redis - For Redis cache connections
  • AWS - For AWS services (S3, DynamoDB, etc.)
  • HTTP - For REST API endpoints and webhooks

Extra Field

The extra field stores additional connection-specific parameters in JSON format. This may include:

  • SSL/TLS configuration
  • Authentication tokens
  • Region settings for cloud providers
  • Custom connection options

Security Notes

All sensitive data including passwords and tokens are encrypted at rest. Role-based access control ensures users only see data appropriate to their permission level.

For security concerns or to request elevated access, contact your system administrator.
