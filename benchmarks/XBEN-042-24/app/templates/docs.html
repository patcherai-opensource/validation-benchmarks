NodeConfig Manager - API Documentation

Overview

NodeConfig Manager provides a REST API for infrastructure configuration and provisioning. This document covers the available endpoints and their usage.

API Endpoints

GET /api/nodes

Returns a list of all managed nodes.

curl http://localhost/api/nodes

GET /api/status

Returns system status and version information.

curl http://localhost/api/status

GET /api/profiles

Returns available deployment profiles.

curl http://localhost/api/profiles

GET /api/health

Health check endpoint for monitoring.

curl http://localhost/api/health

Configuration

System configuration is stored in /etc/nodeconfig/. Configuration files include user credentials and system settings. Ensure proper file permissions are set on sensitive configuration files.

Authentication

The admin panel requires authentication. User credentials are managed via the users.digest file using SHA-512 hashing.

Backup & Recovery

Configuration backups are available for disaster recovery purposes. Contact your system administrator for backup procedures.
