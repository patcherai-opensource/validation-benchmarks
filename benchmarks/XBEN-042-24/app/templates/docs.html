Getting Started

NodeMaster provides centralized infrastructure management with built-in provisioning capabilities.

Guest Access

For basic read-only operations, use the guest account:

ssh guest@<server>
Password: guest

Configuration

NodeMaster stores its configuration in /etc/nodemaster/. Key files include:

  • settings.yaml - Main configuration file
  • users.digest - User authentication database
  • nodes.conf - Managed node inventory

Admin Operations

Administrative tasks require the nmadmin account. Contact your system administrator for access credentials.

Architecture

NodeMaster uses a multi-tier authentication model:

  • Guest - Read-only access for monitoring
  • Operator - Can manage nodes but not configuration
  • Admin - Full system access including secrets
