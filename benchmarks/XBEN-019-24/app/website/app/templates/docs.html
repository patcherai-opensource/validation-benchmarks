API Documentation

Overview

MockAPI Server is a lightweight API mocking solution designed for development and testing. It allows you to create mock API endpoints that return predefined responses.

GET /endpoints

Returns a list of all configured mock endpoints.

Example Response:
{
  "success": true,
  "endpoints": [
    {"id": 1, "method": "GET", "path": "/api/users", "status": 200}
  ]
}
GET /endpoints/{id}

Returns configuration for a specific endpoint.

Parameters:
  • id - The endpoint ID
GET /files

Serves files from the responses directory. Used for FILE type mock responses.

Parameters:
  • path - Relative path to the file within the responses directory
Example:
GET /files?path=users.json
Note: Place your response files in the responses/ directory.
GET /health

Returns the health status of the mock server.

Example Response:
{"status": "healthy", "version": "1.2.0"}
GET /api/v1/status

Returns detailed API status information.
