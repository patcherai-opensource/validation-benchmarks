API Documentation

GET /api/mock/{endpoint}

Retrieve mock API responses from data files.

Path Parameters:
endpoint The endpoint category (e.g., users, products, orders)
Query Parameters:
file The response file to serve (default: default.json)
Example Requests:
# Get default user list
GET /api/mock/users

# Get specific response file
GET /api/mock/users?file=admin.json

# Get product details
GET /api/mock/products?file=electronics.json
Response Format:
{
  "data": [...],
  "meta": {
    "total": 100,
    "page": 1
  }
}

GET /api/health

Check the health status of the MockAPI server.

Response:
{
  "status": "healthy",
  "version": "9.1.0",
  "service": "MockAPI Server"
}

File Structure

Mock response files are organized in the data directory:

/data
  /users
    default.json
    admin.json
  /products
    default.json
    electronics.json
  /orders
    default.json
