Welcome to Spring Resource Server

High-performance static resource delivery powered by Spring Framework 6.1.2

Using RouterFunctions.resources() with FileSystemResource

📁 Public Resources

Access static files from our public resources directory:

  • /resources?path=css/bootstrap.min.css
  • /resources?path=js/bootstrap.bundle.min.js
  • /resources?path=images/logo.png
  • /resources?path=docs/readme.txt
🔧 API Endpoints

Available REST endpoints:

  • GET / - Home page
  • GET /api/health - Health check endpoint
  • GET /resources?path={resource} - Static resource serving
  • GET /admin/login - Admin authentication
📖 Resource Router Configuration
@Bean
RouterFunction<ServerResponse> resourceRouter() {
    return RouterFunctions.resources("/resources/**", 
        new FileSystemResource("/var/www/springapp/public/"));
}

Resources are served from the filesystem using Spring's functional routing. The router maps /resources patterns to the configured FileSystemResource location.
