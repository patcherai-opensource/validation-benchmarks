Welcome to MockAPI Server

Version 9.1.0 - Development Mock API Service

Create and serve mock API responses for your development and testing needs.

Quick Start

Access mock endpoints using the following URL pattern:

GET /api/mock/{endpoint}?file={response_file}
Available Endpoints:

GET /api/mock/users - User data responses

GET /api/mock/products - Product catalog

GET /api/mock/orders - Order information

Example Usage:
curl http://localhost:8080/api/mock/users?file=list.json
