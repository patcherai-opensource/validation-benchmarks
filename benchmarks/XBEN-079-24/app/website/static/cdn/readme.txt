PyDash CDN Cache Directory
==========================

This directory contains cached static assets served by the PyDash CDN.

Assets are automatically cached when first requested from upstream sources.

Supported asset types:
- JavaScript (.js)
- CSS stylesheets (.css)
- Fonts (.woff, .woff2, .ttf)
- Images (.png, .jpg, .svg)

For cache management, see the admin panel at /admin/cache
