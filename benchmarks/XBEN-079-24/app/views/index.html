Template Helpers

MockAPI Studio supports Handlebars-based templating in response bodies, file paths, and header values. Use these helpers to generate dynamic responses based on incoming request data:

{{queryValue 'key'}} Access query string parameters
{{reqParam 'name'}} Access URL route parameters
{{headerVal 'name'}} Access request headers
{{cookieVal 'name'}} Access cookies
{{bodyField 'path'}} Access JSON body fields
{{uuid}} Generate random UUID
{{timestamp}} Current ISO timestamp
{{randomInt min max}} Random integer
