CycloneDX BOM Analyzer

v0.9.3

Software Bill of Materials analysis and validation service for CycloneDX XML format.

API Endpoints

  • POST /api/v1/bom/upload Upload and analyze a CycloneDX BOM
  • POST /api/v1/bom/validate Validate a BOM against detected schema
  • GET /api/v1/bom/list List all analyzed BOMs
  • GET /api/v1/bom/{id} Retrieve analysis results
  • GET /api/v1/bom/{id}/components List components in a BOM
  • GET /api/v1/bom/{id}/export Download original BOM file
  • GET /api/v1/schema/versions List supported schema versions

Quick Start

Upload BOM via Web UI

Or use the API directly:

# Upload a BOM file
curl -X POST -F "file=@sbom.xml" http://localhost:8080/api/v1/bom/upload

# Validate a BOM
curl -X POST -F "bom=<xml content>" http://localhost:8080/api/v1/bom/validate

# List supported schema versions
curl http://localhost:8080/api/v1/schema/versions

Supported Formats

CycloneDX XML BOM versions 1.0 through 1.6. JSON format support is planned for a future release.
