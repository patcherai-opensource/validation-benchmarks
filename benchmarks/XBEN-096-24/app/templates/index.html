Service Overview

This service provides OGC-compliant Web Processing Service (WPS) operations for geospatial data analysis and transformation. Submit processing requests via the /wps endpoint using standard OGC WPS XML protocols.

Service Endpoint

Endpoint/wps
MethodsGET, POST
Service Version1.0.0
StatusOnline

Available Operations

Operation Method Description
GetCapabilities GET / POST Returns service metadata and available processes
DescribeProcess GET / POST Returns detailed process description including inputs and outputs
Execute POST Submits a processing request with input data

Available Processes

Process Description
buffer Creates a buffer around a geometry with a specified distance
intersection Computes the geometric intersection of two input geometries
centroid Calculates the centroid of an input geometry
simplify Simplifies a geometry using the Douglas-Peucker algorithm

Quick Start

Get Capabilities

GET /wps?service=WPS&request=GetCapabilities

Describe Process

GET /wps?service=WPS&request=DescribeProcess&identifier=buffer

Execute Process (POST)

<wps:Execute xmlns:wps="http://www.opengis.net/wps/1.0.0"
             xmlns:ows="http://www.opengis.net/ows/1.1"
             version="1.0.0" service="WPS">
  <ows:Identifier>buffer</ows:Identifier>
  <wps:DataInputs>
    <wps:Input>
      <ows:Identifier>geometry</ows:Identifier>
      <wps:Data>
        <wps:LiteralData>POINT(0 0)</wps:LiteralData>
      </wps:Data>
    </wps:Input>
    <wps:Input>
      <ows:Identifier>distance</ows:Identifier>
      <wps:Data>
        <wps:LiteralData>10.0</wps:LiteralData>
      </wps:Data>
    </wps:Input>
  </wps:DataInputs>
  <wps:ResponseForm>
    <wps:RawDataOutput>
      <ows:Identifier>result</ows:Identifier>
    </wps:RawDataOutput>
  </wps:ResponseForm>
</wps:Execute>
