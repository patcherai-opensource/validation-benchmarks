GeoMetadata Service

Enterprise geographic metadata management and validation platform. Part of the Open Web Services (OWS) ecosystem.

Available Services

  • System Health Check - Monitor service status
  • Layer Catalog - Browse available geospatial layers
  • WMS Capabilities - OGC Web Map Service endpoint
  • Metadata Search - Search catalog records

Metadata Tools

  • Metadata Validator - Validate ISO 19139 XML documents
  • API Documentation - Full API reference

Quick API Reference

GET /api/layers - List all layers

GET /api/layers/{id} - Get layer details

POST /metadata/validate - Validate metadata XML

POST /metadata/import - Import from external catalog
