FontForge SVG Processor

A web-based tool for processing SVG content from OpenType-SVG (OT-SVG) font files.

Features

  • SVG Glyph Extraction - Parse and extract SVG glyphs from font data
  • Font Subsetting Support - Process SVG tables for font subsetting operations
  • OT-SVG Compatibility - Full support for OpenType SVG table format

Available Endpoints

  • /subset - Process SVG content from font files
  • /api/info - Service information (JSON)
