GeoMetadata Service API Documentation

Version 2.3.1 | REST API Reference

Authentication

Most read endpoints are publicly accessible. Write operations require authentication via the /login endpoint.

Endpoints

GET /api/health

Returns system health status and version information.

{"status": "healthy", "version": "2.3.1"}

GET /api/layers

Returns a list of all available geospatial layers.

GET /api/layers/{layer_id}

Returns details for a specific layer.

POST /metadata/validate

Validates an ISO 19139 metadata XML document.

Parameters:

  • metadata (form data) - The XML document content to validate

Example:

curl -X POST http://localhost:8080/metadata/validate \
  -d "metadata=<xml>...</xml>"

POST /metadata/import

Queue an import job from an external catalog. (Requires authentication)

Parameters:

  • catalog_url (form data) - URL of the external CSW catalog

GET /metadata/search

Search metadata records in the catalog.

Parameters:

  • q (query string) - Search query

GET /capabilities

Returns WMS GetCapabilities XML document (OGC compliant).

Supported Formats

  • ISO 19139 Geographic Metadata XML
  • OGC WMS Capabilities
  • GML (Geography Markup Language)
