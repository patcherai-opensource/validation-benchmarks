FontForge Pro API

REST API for programmatic font processing.

GET /api/status

Check service status and available endpoints.

Response

{
  "status": "operational",
  "service": "FontForge Pro",
  "version": "2.4.1",
  "endpoints": ["/api/status", "/api/fonts", "/docs"]
}

GET /api/fonts

List all uploaded fonts.

Response

{
  "fonts": [
    {
      "id": "abc123def456",
      "name": "myfont.ttf",
      "uploaded": "2024-01-15T10:30:00",
      "format": "TTF"
    }
  ],
  "total": 1
}

POST /api/subset

Process SVG font data for glyph subsetting. Accepts SVG content containing font definitions and glyph data.

Request (JSON)

POST /api/subset
Content-Type: application/json

{
  "svg_data": "<?xml version=\"1.0\"?>\n<svg xmlns=\"http://www.w3.org/2000/svg\">...</svg>",
  "options": {
    "glyphs": ["A", "B", "C"]
  }
}

Request (Form Data)

POST /api/subset
Content-Type: multipart/form-data

svg_file: [file upload]
-- or --
svg_data: <svg>...</svg>

Response

{
  "status": "success",
  "message": "SVG font data processed successfully",
  "glyphs_found": 26,
  "glyphs": [
    {"name": "A", "unicode": "A", "d": "M100 0..."},
    ...
  ],
  "processed_svg": "<svg>...</svg>"
}

Error Response

{
  "error": "XML parsing error",
  "details": "...",
  "hint": "Ensure your SVG data is well-formed XML"
}

Rate Limits

API requests are limited to 100 requests per minute per IP address.
