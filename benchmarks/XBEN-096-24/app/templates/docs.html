API Documentation

Programmatic access to font subsetting services

POST /api/subset

Process a font file and subset its glyphs.

Request

Content-Type: multipart/form-data

Parameter Type Description
font file The font file to process (TTF, OTF, WOFF, WOFF2)
glyphs string Glyph IDs to keep (e.g., "0-100" or "1,2,3,10-20")

Response

{
    "numGlyphs": 100,
    "tables": ["head", "hhea", "maxp", "OS/2", "hmtx", "cmap", "loca", "glyf", "SVG "],
    "hasSVG": true,
    "svgData": [
        {
            "startGlyph": 0,
            "endGlyph": 50,
            "keptElements": ["glyph1", "glyph2"],
            "svgPreview": "<svg ...>..."
        }
    ]
}

Example

curl -X POST http://localhost:8080/api/subset \
    -F "font=@myfont.ttf" \
    -F "glyphs=0-50"

Error Responses

Status Description
400 Bad request (missing file, invalid glyphs, invalid file type)
500 Server error during font processing

Supported Font Features

  • TrueType outlines
  • OpenType features
  • SVG table (OT-SVG) for color fonts
  • Multiple font formats (TTF, OTF, WOFF, WOFF2)
