API Documentation

Authentication

Most API endpoints require authentication using an API token. You can provide the token in two ways:

  • HTTP Header: X-Auth-Token: your-token-here
  • Query Parameter: ?token=your-token-here

Contact your administrator to obtain an API token for your agent.

Note: Agent tokens follow the format agent-token-XXXXXX where XXXXXX is a 6-character hex identifier.

Endpoints

GET /api/health

Public

Health check endpoint. Returns service status.

$ curl http://localhost/api/health
{"status":"healthy","service":"configsync","version":"2.1.4"}

GET /api/v1/environments

Public

List all available environments.

$ curl http://localhost/api/v1/environments
{"environments":["base","production","development"],"default":"base"}

GET /api/v1/files

Authenticated

List files in an environment.

Parameters:

  • env - Environment name (default: "base")
  • token - API token (can also use header)
$ curl "http://localhost/api/v1/files?env=base&token=YOUR_TOKEN"

GET /api/v1/file/fetch

Authenticated

Fetch a configuration file from the file server.

Parameters:

  • path - Path to the file (relative to file root) [required]
  • env - Environment name (default: "base")
  • token - API token (can also use header)
$ curl "http://localhost/api/v1/file/fetch?path=nginx.conf&env=base&token=YOUR_TOKEN"

POST /api/v1/config/validate

Authenticated

Validate configuration file syntax.

Request Body:

{"content": "your-config-content-here"}

POST /api/v1/sync/trigger

Admin Only

Trigger a configuration sync to all agents.
