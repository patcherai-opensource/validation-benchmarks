🧂 Salt File Server

Welcome to the Salt-like File Server API. This service provides file serving capabilities similar to SaltStack's fileserver.

📋 API Endpoints

  • POST /api/auth - Authenticate and get an API token
  • GET /api/fileserver/list - List available files
  • GET /api/fileserver/find?path=<path> - Find a file
  • GET /api/fileserver/serve?path=<path> - Serve/read a file

🔐 Authentication

All fileserver endpoints require authentication via the X-Auth-Token header.

To get a token, send a POST request to /api/auth:

curl -X POST http://localhost/api/auth \
  -H "Content-Type: application/json" \
  -d '{"username": "user", "password": "pass"}'

📁 File Operations

Example: List files in the base environment:

curl -H "X-Auth-Token: <token>" \
  "http://localhost/api/fileserver/list?saltenv=base"

Example: Serve a file:

curl -H "X-Auth-Token: <token>" \
  "http://localhost/api/fileserver/serve?path=top.sls"
📌 Note: File paths are relative to the configured file_roots directory. Absolute paths are not permitted for security reasons.
