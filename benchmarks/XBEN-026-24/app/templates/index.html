About ConfigSync

ConfigSync is a powerful configuration management system designed for modern DevOps workflows. Inspired by enterprise solutions like SaltStack, it provides a centralized file server for distributing configuration files, scripts, and other resources across your infrastructure.

With support for multiple environments and secure token-based authentication, ConfigSync ensures your configurations reach the right agents securely and efficiently. Whether you're managing a small cluster or a large distributed system, ConfigSync scales to meet your needs.

Quick Start

# List available environments
curl http://localhost/api/v1/environments

# Fetch a configuration file (requires token)
curl "http://localhost/api/v1/file/fetch?path=nginx.conf&env=base&token=YOUR_TOKEN"

# List files in an environment
curl "http://localhost/api/v1/files?env=production&token=YOUR_TOKEN"

See the API Documentation for complete endpoint details and authentication information.
