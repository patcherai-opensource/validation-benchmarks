API Documentation

Authentication

Obtain an authentication token via the login endpoint:

POST /login
Content-Type: application/json

{
  "username": "your_username",
  "password": "your_password"
}
File Server API

Access files using the token in X-Auth-Token header:

GET /api/v1/file/list?saltenv=base
GET /api/v1/file/serve?path=init.sls
GET /api/v1/envs
