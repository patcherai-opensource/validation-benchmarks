About ConfigSync

Our Mission

ConfigSync was developed to solve the challenge of configuration management in modern distributed systems. Our goal is to provide a simple, secure, and scalable solution for distributing configuration files across your infrastructure.

Architecture

ConfigSync uses a centralized file server model where configuration files are organized into environments. Each environment (base, production, development) has its own file root, ensuring isolation between different deployment stages.

File Roots

  • base - Common configurations shared across all environments
  • production - Production-specific configurations
  • development - Development and testing configurations

Security Model

All file fetch operations require authentication via API tokens. Tokens can be provided either through the X-Auth-Token header or as a query parameter. This ensures that only authorized agents can access configuration files.

Additionally, ConfigSync implements path validation to prevent unauthorized file access outside the designated file roots.
