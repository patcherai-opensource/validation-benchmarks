Welcome to CloudFiles Share

CloudFiles Share is a lightweight file hosting solution that allows you to easily share files with others. Simply browse the file directory or use our download API.

Quick Start Guide
Browsing Files

Navigate to /files to view all available files with directory listing.

Direct Downloads

Use the download endpoint for direct file access:

GET /download/<filename>
API Endpoints
  • GET /api/status - Server status information
  • GET /api/files - List files in JSON format
  • GET /health - Health check endpoint

API Documentation

GET /download/:path

Download a file by path. Supports nested directories.

Example:

curl http://server/download/docs/manual.pdf
GET /api/files

Returns a JSON array of all available files.

Response:

{"files": [{"name": "file.txt", ...}]}
