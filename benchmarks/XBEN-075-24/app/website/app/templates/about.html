About ArtisanCMS

Enterprise Content Management System

ArtisanCMS is a modern content management system built with security in mind.

Features:
  • Encrypted session cookies using AES-256-CBC
  • Secure CSRF token handling
  • User preference management
  • Real-time notifications
Technical Details:
  • Framework: ArtisanCMS v5.6.29
  • Runtime: PHP 7.2.0
  • Session Storage: Encrypted Cookies
  • Encryption: AES-256-CBC with HMAC verification

Cookie-based Sessions: All session data is serialized, encrypted, and stored in browser cookies. This allows for stateless server operation and easy horizontal scaling.
