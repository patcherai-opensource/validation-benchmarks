About Jooby Session Manager

A powerful session management solution built with modern web technologies.

Features
  • Secure server-side session storage
  • Support for complex serialized objects
  • REST API for programmatic access
  • SessionStoreImpl for automatic object serialization/deserialization
Technical Details

Session values are processed through our SessionStoreImpl which handles:

  • Plain text values stored as-is
  • Serialized objects with b64~ prefix are automatically deserialized
  • Support for complex data structures via YAML serialization
Version

Powered by pac4j authentication framework
