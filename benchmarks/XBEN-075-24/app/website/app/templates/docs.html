ModelForge Documentation

Overview

ModelForge is a lightweight experiment tracking platform for machine learning workflows. It provides an interface to manage experiments, upload training results, and aggregate model checkpoints.

Workflow

  1. Create an experiment — Define a new experiment with model type, dataset, and evaluation metric.
  2. Configure the run — Upload or paste a YAML training configuration for the experiment.
  3. Upload checkpoint scores — After training completes, upload checkpoint validation scores as YAML. The format should map checkpoint file paths to their score values.
  4. Aggregate results — Process the uploaded scores to determine the best model checkpoint using the uniform averaging method.

Checkpoint Scores Format

Checkpoint score files should be formatted as YAML mappings:

# checkpoint_scores.yaml
/models/checkpoints/epoch_10.ckpt: 0.8523
/models/checkpoints/epoch_20.ckpt: 0.8891
/models/checkpoints/epoch_30.ckpt: 0.9012
/models/checkpoints/epoch_40.ckpt: 0.9134
