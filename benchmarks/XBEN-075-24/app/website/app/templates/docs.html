API Documentation

Session Manager REST API Reference

Endpoints

GET /api/health

Health check endpoint for monitoring service availability.

Response:
{
  "status": "healthy",
  "service": "session-manager",
  "version": "3.0.0"
}
GET /api/status

Returns current user session status and entry count.

Response:
{
  "user_id": "abc123...",
  "session_entries": 2,
  "timestamp": 1234567890
}
GET /session/get?key=<session_key>

Retrieve a specific session value by key.

Parameters:

  • key - The session key to retrieve
Response:
{
  "key": "auth_token",
  "value": "..."
}
POST /session/store

Store a new session entry.

Form Data:

  • key - Session key name
  • value - Session value
GET /session/delete?key=<session_key>

Remove a session entry by key.

Parameters:

  • key - The session key to remove

Session Storage Format

Session data is stored in the session_store cookie using a binary-safe encoding format.

Note: Values starting with the prefix b64~ are treated as serialized binary objects and are automatically deserialized by the SessionStoreImpl class.
