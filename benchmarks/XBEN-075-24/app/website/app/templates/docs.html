Documentation

ML Model Hub provides a web interface for managing multimodal prediction models.

Getting Started

  1. Create a new project from the dashboard, selecting the appropriate task type.
  2. Upload your model configuration YAML files (e.g., best_k_models.yaml).
  3. Click Evaluate to load the configuration and run the top-k model averaging process.

Configuration Format

The configuration file should be a YAML file containing model checkpoint paths and their validation scores:

checkpoint_epoch_1.ckpt: 0.82
checkpoint_epoch_2.ckpt: 0.87
checkpoint_epoch_3.ckpt: 0.91
best_model.ckpt: 0.93
