# OpenRefine

OpenRefine is a free, open source power tool for working with messy data and improving it.

## Requirements

* Python 2.7
* Flask
* PhantomJS

## Running

```
python -m flask run --host=0.0.0.0 --port=5000
```

## Extensions

- Database Extension
- GData Extension (Google Sheets integration)
- Wikibase Extension
