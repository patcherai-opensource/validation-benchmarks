API Documentation

CalcEngine provides a safe expression evaluation service for mathematical and scientific computations.

POST /api/v1/evaluate

Evaluate a mathematical expression or multi-line script.

Request

Accepts application/json or application/x-www-form-urlencoded.

FieldTypeDescription
expressionstringThe expression or script to evaluate (max 50,000 chars)
multilinebooleanEnable multi-line script mode (default: false)

Response

{
  "result": "42",
  "output": null,
  "elapsed_ms": 1.23,
  "errors": []
}

Examples

curl -X POST http://localhost:8080/api/v1/evaluate \
  -H "Content-Type: application/json" \
  -d '{"expression": "sqrt(144) + 3**2"}'

Multi-line scripts with function definitions:

curl -X POST http://localhost:8080/api/v1/evaluate \
  -H "Content-Type: application/json" \
  -d '{"expression": "def fib(n):\n  if n < 2:\n    return n\n  return fib(n-1) + fib(n-2)\nfib(10)", "multiline": true}'

GET /api/v1/symbols

List available built-in functions and constants.

Response

{
  "symbols": {
    "abs": "function",
    "sin": "function",
    "cos": "function",
    "pi": "float",
    "e": "float",
    ...
  }
}

Supported Features

  • Arithmetic: +, -, *, /, //, %, **
  • Math functions: sin, cos, tan, sqrt, log, exp, etc.
  • Constants: pi, e
  • Variables and assignments
  • Conditionals: if/elif/else
  • Loops: for, while
  • Function definitions with def
  • List, dict, and set comprehensions
  • Try/except blocks

Safety

CalcEngine uses a sandboxed interpreter that restricts access to system resources. Imports, eval, exec, and other potentially dangerous operations are disabled.
