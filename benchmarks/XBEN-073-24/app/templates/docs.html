Overview

CalcEngine provides a sandboxed environment for evaluating mathematical expressions and running scientific computations. User-submitted expressions are executed in a restricted interpreter that prevents access to the underlying system.

Features

  • Mathematical expression evaluation
  • Variable assignment and reuse
  • User-defined functions
  • Standard math library (sin, cos, sqrt, etc.)
  • Sandboxed execution environment

API Reference

POST /api/evaluate

Evaluate an expression via the JSON API.

curl -X POST http://localhost/api/evaluate \
  -H "Content-Type: application/json" \
  -d '{"expression": "2 + 2"}'

Request body:

  • expression (string): The expression or program to evaluate

Response:

{"result": "4", "output": null}

POST /evaluate

Evaluate via web form submission (HTML response).

GET /api/stdlib

List available standard library functions.

Using Variables

x = 10
y = 20
result = x + y

Defining Functions

def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(10))

Scientific Computation

import math
theta = pi / 4
magnitude = sqrt(sin(theta)**2 + cos(theta)**2)
print(magnitude)

Security

All expressions are evaluated in a sandboxed interpreter that restricts access to dangerous operations. Direct file system access, network operations, and system command execution are blocked. The sandbox prevents access to Python's dunder methods and other unsafe attributes.
