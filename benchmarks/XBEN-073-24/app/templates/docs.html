Health Check

GET /api/v1/health

Check API health status.

Response

{
    "status": "healthy",
    "version": "2.6.0"
}

Read File

POST /api/v1/vision/read_file

Read an image file and return its contents as base64-encoded data. This endpoint wraps the paddle.vision.ops.read_file function.

Request Body

{
    "filename": "/path/to/image.jpg"
}

Response

{
    "status": "success",
    "filename": "/path/to/image.jpg",
    "size": 12345,
    "content": "base64_encoded_content...",
    "encoding": "base64"
}

Example

curl -X POST http://localhost/api/v1/vision/read_file \
    -H "Content-Type: application/json" \
    -d '{"filename": "/app/sample_images/sample.jpg"}'

Analyze Image

POST /api/v1/vision/analyze

Analyze an image file and return metadata including format, dimensions, and data type information.

Request Body

{
    "filename": "sample.jpg"
}

Response

{
    "status": "success",
    "filename": "/app/sample_images/sample.jpg",
    "size": 12345,
    "analysis": {
        "format": "detected",
        "dimensions": "N/A",
        "channels": 3,
        "dtype": "uint8"
    }
}

Error Responses

All endpoints may return the following error responses:

  • 400 - Bad Request: Missing or invalid parameters
  • 403 - Forbidden: Permission denied
  • 404 - Not Found: File or resource not found
  • 500 - Internal Server Error
