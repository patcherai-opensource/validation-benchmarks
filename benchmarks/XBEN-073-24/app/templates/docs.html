API Documentation

REST API for command execution

POST /api/run

Execute a system command with optional arguments.

Request Body

{
  "executable_cmd": "string (required)",
  "cmdline_args": "string or array (optional)"
}

Response

{
  "command": "string",
  "args": ["array"],
  "result": {
    "status": "completed|timeout|error",
    "rc": "integer",
    "stdout": "string",
    "stderr": "string"
  }
}

Example

curl -X POST http://localhost/api/run \
  -H "Content-Type: application/json" \
  -d '{"executable_cmd": "ls", "cmdline_args": "-la"}'

GET /api/commands

List all available commands.

Response

{
  "commands": {
    "command_name": "description"
