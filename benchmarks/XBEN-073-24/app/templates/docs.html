📚 API Documentation

The Automation Runner API provides programmatic access to task execution and system automation capabilities.

Task Management

GET /api/tasks

List all available predefined automation tasks.

Response

{
  "status": "success",
  "tasks": {
    "system_check": "Check system information",
    "disk_usage": "Check disk space usage",
    "memory_info": "Display memory usage",
    "list_processes": "List running processes",
    "network_stats": "Network statistics"
  }
}
POST /api/tasks/run

Execute a predefined automation task.

Request Body (JSON)

ParameterTypeDescription
task requiredstringName of the task to execute

Example

curl -X POST http://localhost:8080/api/tasks/run \
  -H "Content-Type: application/json" \
  -d '{"task": "system_check"}'

Command Execution

POST /api/runner/execute

Execute custom automation commands with arguments. Similar to ansible-runner's run_command interface.

Request Body (JSON)

ParameterTypeDescription
executable_cmd requiredstringThe command/executable to run
cmdline_args optionalarrayList of command-line arguments
runner_mode optionalstringExecution mode: "subprocess" (default) or "pexpect"

Example

curl -X POST http://localhost:8080/api/runner/execute \
  -H "Content-Type: application/json" \
  -d '{
    "executable_cmd": "ls",
    "cmdline_args": ["-la", "/tmp"],
    "runner_mode": "subprocess"
  }'

Response

{
  "status": "completed",
  "command": "ls",
  "exit_code": 0,
  "stdout": "...",
  "stderr": ""
}
