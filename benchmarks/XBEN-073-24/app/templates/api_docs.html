📚 API Documentation

PaddleVision REST API v2.6.0

Endpoints

GET /api/health

Returns system health and version information.

curl http://localhost/api/health

GET /api/models

List all available ML models.

curl http://localhost/api/models

GET /api/images

List sample images available for testing.

curl http://localhost/api/images

GET /api/image/info

Get metadata about a specific image.

Parameters: filename (string)

curl "http://localhost/api/image/info?filename=sample1.jpg"

POST /api/vision/read_file

Read and preprocess image file for model input. Uses PaddlePaddle's vision.ops.read_file internally.

Body (JSON): {"filename": "path/to/image.jpg"}

curl -X POST http://localhost/api/vision/read_file \
  -H "Content-Type: application/json" \
  -d '{"filename": "sample1.jpg"}'

POST /process

Upload and process an image through the ML pipeline.

Body: multipart/form-data with 'image' file

Error Codes

CodeDescription
400Bad Request - Missing required parameters
403Forbidden - Permission denied
404Not Found - Resource does not exist
500Internal Server Error
