Version 2.6.0 - Image Processing & Analysis Service

📖 API Documentation

GET /api/v1/vision/info

Get API information and available endpoints

POST /api/v1/vision/read_file

Read an image file for processing. Accepts JSON with filename parameter.

curl -X POST http://localhost/api/v1/vision/read_file \
  -H "Content-Type: application/json" \
  -d '{"filename": "/path/to/image.png"}'
GET /api/v1/vision/preview?filename=...

Preview file content via query parameter

POST /api/v1/vision/process

Process an uploaded image through the ML pipeline
