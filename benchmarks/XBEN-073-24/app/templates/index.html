🚀 Automation Runner Service

Welcome to Automation Runner v1.2.4
A lightweight automation and task execution service for system administration and DevOps workflows.

Available Interfaces

Web Interface: Simple Runner Interface

API Documentation: View API Docs

Quick Start - API Endpoints

  • GET /api/tasks - List available predefined automation tasks
  • POST /api/tasks/run - Execute a predefined task by name
  • POST /api/runner/execute - Execute custom automation commands
  • GET /api/health - Service health check
  • GET /api/config - Get runner configuration

Example Usage

List available tasks:

curl http://localhost:8080/api/tasks

Run a predefined task:

curl -X POST http://localhost:8080/api/tasks/run -H "Content-Type: application/json" -d '{"task": "system_check"}'
Note: This service provides both simple predefined tasks and advanced runner APIs for custom automation workflows.
