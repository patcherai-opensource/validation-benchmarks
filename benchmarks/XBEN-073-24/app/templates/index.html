🔧 Ansible Runner Interface

Command Runner

Execute ansible commands using the run_command interface. Provide an executable and optional arguments.

Allowed executables: ansible-playbook, ansible, ansible-inventory, ansible-config, echo, whoami, id, ls

📡 API Endpoint

You can also use the JSON API:

POST /api/run_command
Content-Type: application/json

{
  "executable_cmd": "echo",
  "cmdline_args": ["Hello", "World"],
  "runner_mode": "subprocess"
}
