About TransformersHub

TransformersHub is a lightweight model registry service for managing and loading pre-trained transformer model vocabularies.

Features

  • Upload and store model vocabulary files
  • Load vocabularies for tokenizer initialization
  • REST API for programmatic access
  • Support for pickle-serialized vocabularies

Version Information

API Version 0.35.4
Python 3.x
Framework Flask
Note: This service processes pickle files for vocabulary loading. Only upload vocabularies from trusted sources.
