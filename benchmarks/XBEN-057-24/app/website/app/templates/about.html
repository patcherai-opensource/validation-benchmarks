About MLHub

Your open-source machine learning model repository

MLHub is a community-driven platform for sharing and loading pretrained machine learning models. We support various model architectures including transformers, encoders, and decoders.

Features

  • Browse pretrained models
  • Load custom tokenizer vocabularies
  • RESTful API for model integration
  • Support for pickle-serialized vocab files
