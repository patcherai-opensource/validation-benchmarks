About Whoogle Search

What is Whoogle?

Whoogle Search is a self-hosted, ad-free, privacy-respecting metasearch engine. It proxies your searches through Google (or other engines) while stripping out ads, trackers, AMP links, and other privacy-invasive elements.

Features

  • No ads or sponsored content
  • No JavaScript required
  • No cookies (unless you save preferences)
  • No tracking or IP logging
  • Tor and HTTP/SOCKS proxy support
  • Autocomplete/search suggestions
  • POST request search support
  • Custom CSS theming
  • View images directly with full size
  • Light/dark/system theme modes
  • Easily deployable via Docker

Privacy

Whoogle routes your search queries through the server, meaning search engines never see your IP address or personal information. No logs are kept, and preferences are stored entirely client-side using URL-safe encoded tokens.

Open Source

Whoogle Search is open source software. View the source code, report issues, or contribute on GitHub.
