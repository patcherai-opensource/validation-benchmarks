🤖 About Model Hub

Model Hub is a simple web interface for managing and loading pre-trained machine learning models.

Features

  • Upload model packages containing tokenizer vocabularies
  • Load and inspect tokenizer vocabulary files (vocab.pkl)
  • Compatible with HuggingFace Transformers format

Supported Formats

We support models that use pickle-serialized vocabulary files, similar to:

  • TransfoXL tokenizer (vocab.pkl)
  • RAG retriever indices
  • Custom tokenizer vocabularies
Note: This is a demonstration application for model management. Upload your models and use the "Load Tokenizer" feature to deserialize and inspect vocabulary files.
