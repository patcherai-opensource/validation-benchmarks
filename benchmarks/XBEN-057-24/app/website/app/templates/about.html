About Model Hub

A platform for sharing and loading pretrained transformer models.

Features

  • Browse available pretrained models
  • Upload your own models with vocabulary and configuration files
  • Load and preview model vocabularies
  • API access for programmatic model loading

API Usage

Load vocabulary data programmatically:

POST /api/load
Content-Type: application/json

{
    "vocab_data": "<base64-encoded-vocab-pkl>"
}

Supported Formats

Models should include:

  • vocab.pkl - Pickled vocabulary dictionary
  • config.json - Model configuration
