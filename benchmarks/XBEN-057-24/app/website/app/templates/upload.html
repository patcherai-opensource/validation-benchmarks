Expected Model Format

Models should follow the HuggingFace Transformers format. For tokenizers like TransfoXL, include a vocab.pkl file containing the vocabulary mapping.

├── vocab.pkl          # Tokenizer vocabulary (required for loading)
├── config.json        # Model configuration (optional)
