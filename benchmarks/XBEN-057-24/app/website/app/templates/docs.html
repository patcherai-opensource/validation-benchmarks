API Documentation

REST API endpoints for MLHub integration

GET /api/models

List all available pretrained models

Response:
{"models": [...], "total": 3}
GET /api/models/<model_id>/info

Get detailed information about a specific model

Parameters:
  • model_id - The model identifier (e.g., bert-base)
POST /api/tokenizer/upload

Upload a tokenizer vocabulary file

Request:
  • Content-Type: multipart/form-data
  • Field: vocab_file - The vocabulary file (.pkl, .bin)
Response:
{"status": "success", "vocab_type": "dict", "vocab_size": 30522}
POST /api/tokenizer/process

Process base64-encoded vocabulary data

Request:
{"vocab_data": "base64_encoded_pickle_data"}
Response:
{"status": "success", "vocab_type": "TokenizerVocab", "processed": true}
GET /api/settings

Get current MLHub settings

Response:
{"trust_remote_code": false, "cache_dir": "/tmp/models", "max_file_size": "16MB"}
GET /health

Health check endpoint

Response:
{"status": "healthy", "version": "2.3.1"}
