📚 API Documentation

TransformersHub REST API v0.35.4

GET /api/models

List all registered models

curl http://localhost:8080/api/models

Response:

{"status": "success", "models": ["bert-base", "gpt2"], "version": "0.35.4"}
POST /api/upload

Upload a model vocabulary via base64-encoded pickle data

curl -X POST http://localhost:8080/api/upload \
  -H "Content-Type: application/json" \
  -d '{"model_name": "my-model", "vocab_data": "<base64-encoded-pkl>"}'

Parameters:

  • model_name - Name for the model (optional)
  • vocab_data - Base64-encoded pickle vocabulary data
POST /api/load/{model_name}

Load a previously uploaded model vocabulary

curl -X POST http://localhost:8080/api/load/my-model

Note: Loading deserializes the vocabulary pickle file for inference preparation.

Form Upload /upload

Upload a vocabulary file via multipart form

curl -X POST http://localhost:8080/upload \
  -F "model_name=my-model" \
  -F "vocab_file=@vocab.pkl"
💡 Supported File Formats

The API accepts .pkl (pickle) vocabulary files compatible with:

  • TransfoXL tokenizers
  • GPT-2 style vocabularies
  • Custom vocabulary mappings (dict-like structures)
