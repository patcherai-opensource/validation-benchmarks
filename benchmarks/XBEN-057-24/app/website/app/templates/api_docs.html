API Documentation

REST API for programmatic access to vector index management.

GET /api/v1/indexes

List all stored vector indexes.

Response
{
  "indexes": [...],
  "count": 0
}
POST /api/v1/indexes/restore

Restore a vector index from serialized bytes. Accepts base64-encoded serialized index data.

Content Types
  • application/json — Send {"serialized": "<base64-data>"}
  • application/octet-stream — Send raw serialized bytes in request body
Example
curl -X POST /api/v1/indexes/restore \
  -H "Content-Type: application/json" \
  -d '{"serialized": "<base64-encoded-data>"}'
Response
{
  "status": "ok",
  "index": {
    "index_id": "...",
    "name": "...",
    "dimension": 128,
    "distance_metric": "cosine",
    "document_count": 0,
    "version": "1.0"
  }
}
POST /indexes/<index_id>/documents

Add documents to a loaded index.

Request Body (JSON)
{
  "documents": [
    {"content": "Document text here", "metadata": {"source": "file.pdf"}}
  ]
}
GET /indexes/<index_id>/export

Export a loaded index as a base64-encoded serialized file (.vidx).
