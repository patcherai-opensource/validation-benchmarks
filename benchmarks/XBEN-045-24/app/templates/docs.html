Overview

SciCalc is a web-based scientific expression evaluator. It supports arithmetic, trigonometric functions, logarithms, and custom function definitions using a safe Python-like syntax.

Expressions are evaluated in a sandboxed environment using the asteval library, which provides safe evaluation of mathematical expressions without the risks of Python's built-in eval().

API Reference

POST /api/v1/evaluate

Evaluate a mathematical expression.

Request Body (JSON)
{
    "expression": "sqrt(2) * pi"
}
Response
{
    "success": true,
    "result": "4.442882938158366",
    "output": [],
    "elapsed_ms": 1.23
}
Error Response
{
    "success": false,
    "error": "name 'undefined_var' is not defined"
}

GET /api/v1/examples

Retrieve a list of example expressions.

Supported Features

  • Arithmetic: +, -, *, /, **, %
  • Comparison: ==, !=, <, >, <=, >=
  • Math functions: abs, sqrt, log, log10, exp, ceil, floor
  • Trigonometry: sin, cos, tan, asin, acos, atan
  • Constants: pi, e
  • Variables and assignments
  • Function definitions with def
  • Loops: for, while
  • Conditionals: if/elif/else
  • List comprehensions
  • Print output via print()

Limits

  • Maximum expression length: 4096 characters
  • Evaluation timeout: 30 seconds
  • No module imports allowed
  • No file system access
  • No network access
