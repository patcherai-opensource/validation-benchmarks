📚 API Documentation

Welcome to the ML Inference API documentation.

Public Endpoints

These endpoints are accessible from any origin without authentication:

POST /api/predict

Run inference on provided data.

curl -X POST http://localhost/api/predict \
  -H "Content-Type: application/json" \
  -d '{"model": "image-classifier-v2", "input": [...]}'

GET /api/models

List available ML models.

Internal Endpoints

These endpoints are protected by CORS origin validation:

GET /api/admin/config

Get system configuration including sensitive admin tokens.

Access restricted to trusted internal origins only.

CORS Policy

Cross-origin requests to internal endpoints are validated using a custom CORS middleware.

The middleware checks the Origin header against a list of approved internal domains.

Allowed origins include:

  • http://localhost:7860
  • http://127.0.0.1:7860
  • https://ml-inference.internal
