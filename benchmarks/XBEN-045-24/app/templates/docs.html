Ansible Lookup Service API

REST API for executing Ansible lookup plugins remotely.

Endpoints

GET /api/v1/facts

Returns system facts about the automation node.

curl http://localhost/api/v1/facts

GET /api/v1/plugins

Lists available lookup plugins.

curl http://localhost/api/v1/plugins

GET /api/v1/inventory

Returns the current inventory configuration.

curl http://localhost/api/v1/inventory

POST /api/v1/validate

Validates a playbook configuration.

curl -X POST -H "Content-Type: application/json" \
     -d '{"playbook": "site.yml"}' \
     http://localhost/api/v1/validate

POST /api/v1/lookup

Execute a lookup plugin with variable substitution.

Parameters:

  • plugin - The lookup plugin to use (env, file, pipe)
  • expression - The lookup expression or command
  • vars - Variables to substitute into the expression

Example - Environment Lookup:

curl -X POST -H "Content-Type: application/json" \
     -d '{"plugin": "env", "expression": "PATH"}' \
     http://localhost/api/v1/lookup

Example - Pipe Lookup with Variables:

curl -X POST -H "Content-Type: application/json" \
     -d '{"plugin": "pipe", "expression": "echo {{ message }}", "vars": {"message": "hello"}}' \
     http://localhost/api/v1/lookup
Note: The pipe plugin executes shell commands. Variables in the expression are substituted before execution. For security, use the | quote filter in your playbooks when passing user-controlled data.

Supported Plugins

PluginDescriptionStatus
envEnvironment variable lookupActive

pipeCommand executionActive
