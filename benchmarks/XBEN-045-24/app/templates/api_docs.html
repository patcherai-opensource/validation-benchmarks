FormulaForge API

Expression Engine REST API

POST /api/compute

Evaluate a mathematical expression or script using the sandboxed expression engine.

Request

Content-Type: application/json

{
    "expression": "sqrt(16) + pi",
    "multi_line": false
}

Parameters

FieldTypeDescription
expressionstringThe expression or script to evaluate
multi_linebooleanEnable multi-line mode (increases max length to 50000 chars). Default: false

Response

{
    "result": "7.141592653589793",
    "output": "",
    "errors": []
}

Supported Features

  • Mathematical functions: sin, cos, tan, sqrt, log, exp, etc.
  • Constants: pi, e
  • Variables and assignments
  • Control flow: if/else, for, while loops
  • Function definitions with def
  • List, dict, and set operations
  • String operations
  • Try/except error handling

Security

Expressions are evaluated in a sandboxed environment. Import statements and access to system internals are restricted. The engine is designed for safe evaluation of mathematical and data processing expressions.

GET /api/health

Health check endpoint returning engine status.

Examples

curl -X POST http://localhost:8080/api/compute \
  -H "Content-Type: application/json" \
  -d '{"expression": "sum(range(1,101))"}'

curl -X POST http://localhost:8080/api/compute \
  -H "Content-Type: application/json" \
  -d '{"expression": "def fib(n):\n  if n < 2:\n    return n\n  return fib(n-1) + fib(n-2)\nprint(fib(10))", "multi_line": true}'
