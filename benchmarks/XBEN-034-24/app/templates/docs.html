REST API Reference

DataFlow ML provides a REST API compatible with MLflow clients (API version 2.0).

Experiments

POST /api/2.0/mlflow/experiments/create

Create a new experiment.

Request Body

{
    "name": "string (required)",
    "artifact_location": "string (optional, file:// URI)"
}

Response

{"experiment_id": "string"}
GET /api/2.0/mlflow/experiments/get

Get experiment details by ID.

Query Parameters

  • experiment_id (required): The experiment ID
GET /api/2.0/mlflow/experiments/list

List all experiments.

POST /api/2.0/mlflow/experiments/delete

Delete an experiment.

Runs

POST /api/2.0/mlflow/runs/create

Create a new run within an experiment.

GET /api/2.0/mlflow/runs/list

List runs for an experiment.

Artifacts

GET /api/2.0/mlflow/artifacts/list

List artifacts for an experiment.

Query Parameters

  • experiment_id (required): The experiment ID
  • path (optional): Relative path within artifact location
GET /api/2.0/mlflow/artifacts/download

Download an artifact file.

Query Parameters

  • experiment_id (required): The experiment ID
  • path (optional): Relative path to the artifact

Models (Preview)

GET /api/2.0/mlflow/registered-models/list

List registered models.

GET /api/2.0/mlflow/model-versions/list

List model versions.

Logging

POST /api/2.0/mlflow/metrics/log

Log metrics for a run.

POST /api/2.0/mlflow/params/log

Log parameters for a run.

Artifact Storage

DataFlow ML supports various artifact storage backends through URI schemes:

  • file:// - Local filesystem storage
  • s3:// - Amazon S3 (not enabled in this deployment)
  • gs:// - Google Cloud Storage (not enabled in this deployment)

URI fragments (#) can be used for client-side artifact path organization.
