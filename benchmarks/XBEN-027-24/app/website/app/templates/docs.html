API Documentation

CloudSync Configuration Manager API v1

Authentication

All API endpoints require session-based authentication. Log in via /login to establish a session.

GET /api/schemas

List available configuration schemas.

Response:

{
    "schemas": [
        {"name": "app_settings", "description": "..."},
        ...
    ]
}

GET /api/config/{config_name}

Retrieve a configuration by name.

Parameters:

  • config_name - Name of the configuration to retrieve

Response:

{
    "config_name": "app_settings",
    "data": { ... }
}

POST /api/config/{config_name}/merge

Merge JSON data into an existing configuration. Uses deep merge to update nested properties without overwriting the entire object.

Security Note: Certain keywords are restricted and cannot be used in configuration updates. The system validates input against a keyword denylist to prevent unauthorized access control modifications.

Request Body:

{
    "settings": {
        "new_property": "value"
    }
}

Response:

{
    "status": "success",
    "config_name": "app_settings",
    "data": { ... merged result ... }
}

POST /api/config

Create a new configuration.

Request Body:

{
    "config_name": "my_config",
    "data": { ... }
}

GET /api/admin/secrets ADMIN

Retrieve system secrets. Requires admin privileges.

Access Control: Checks for is_admin flag in the user's app_settings configuration.

GET /api/admin/configs ADMIN

List all configurations in the system. Requires admin privileges.

GET /api/system/info

Get system information and version details.

GET /api/health

Health check endpoint.

Error Responses

401 Unauthorized: Authentication required

403 Forbidden: Denied keyword detected or admin privileges required

404 Not Found: Configuration does not exist
