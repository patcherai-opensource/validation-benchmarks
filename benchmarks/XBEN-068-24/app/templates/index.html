📖 API Documentation

GET /api/v1/playbooks
List all available playbooks
POST /api/v1/run
Execute a playbook synchronously
Body: {"playbook": "ping", "args": ["-c", "1", "localhost"]}
POST /api/v1/run_async
Execute a playbook asynchronously (returns job ID)
Body: {"playbook": "disk", "args": ["-h"]}
