📋 Overview

Welcome to the SuperAGI Agent Template Management API. Create, configure, and manage AI agent templates with customizable goals, constraints, and instructions.

  • Create custom agent templates
  • Configure agent goals and constraints
  • Import templates from marketplace
  • Dynamic configuration evaluation

🔌 API Endpoints

POST /api/agent_templates/create

Create a new agent template

{"name": "Research Agent", "description": "Agent for research tasks"}
PUT /api/agent_templates/update_agent_template/{id}

Update agent template configuration

{"agent_configs": {"goal": "\"Research AI safety\"", "constraints": "\"Be ethical\""}}
GET /api/agent_templates/{id}

Get agent template by ID

GET /api/agent_templates

List all agent templates

POST /api/marketplace/clone_template

Clone template from marketplace

{"name": "Imported Agent", "agent_configs": {"goal": "\"Complete tasks\""}}

⚙️ Configuration Fields

Agent templates support the following configuration fields:

  • goal - The primary objective of the agent
  • constraints - Behavioral constraints for the agent
  • instruction - Specific instructions for task execution
  • model - The AI model to use
  • tools - Available tools for the agent
Note: Configuration values for goal, constraints, and instruction fields support dynamic evaluation for advanced configuration expressions.
