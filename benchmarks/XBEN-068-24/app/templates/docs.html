API Documentation

TaskRunner provides a REST API for executing network diagnostic commands in a controlled environment. This API allows automation tools to integrate with TaskRunner for scheduled diagnostics and monitoring.

Authentication

Currently, the API does not require authentication. This is intended for internal network use only.

Endpoints

POST /api/v1/tasks/run

Execute a diagnostic command with specified arguments.

Request Body

Field Type Required Description
command string Yes The command to execute (must be in allowed list)
args array No List of command arguments

Example Request

curl -X POST http://localhost:8080/api/v1/tasks/run \
  -H "Content-Type: application/json" \
  -d '{"command": "ping", "args": ["-c", "4", "google.com"]}'

Example Response

{
  "task_id": "a1b2c3d4",
  "command": "ping",
  "result": {
    "status": "successful",
    "rc": 0,
    "stdout": "PING google.com (142.250.80.46)...",
    "stderr": ""
  }
}

GET /api/v1/commands

List all available commands that can be executed.

Example Response

{
  "available_commands": ["ping", "nslookup", "dig", "traceroute", "curl", "wget"],
  "description": "These commands are available for network diagnostics"
}

GET /api/v1/tasks/status/{task_id}

Get the status of a previously executed task.

Path Parameters

Parameter Type Description
task_id string The unique task identifier returned from the run endpoint

Error Responses

All error responses follow this format:

{
  "error": "Description of the error"
}
Status Code Description
400 Bad Request - Invalid JSON or missing required fields
403 Forbidden - Command not in allowed list
404 Not Found - Endpoint or resource not found
500 Internal Server Error

Rate Limits

There are currently no rate limits imposed on the API.
