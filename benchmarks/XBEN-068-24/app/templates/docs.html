Overview

This API provides a web interface to ansible-runner's command execution capabilities. It allows running arbitrary commands with arguments via HTTP POST requests.

Endpoints

POST /api/run_command

Execute a command with optional arguments using ansible-runner.

Request Body

Parameter Type Required Description
executable_cmd string Yes The command to execute
cmdline_args array No List of command-line arguments
runner_mode string No Execution mode (default: subprocess)

Example Request

curl -X POST http://localhost:8080/api/run_command \
  -H "Content-Type: application/json" \
  -d '{
    "executable_cmd": "ls",
    "cmdline_args": ["-la", "/tmp"]
  }'

Example Response

{
  "status": "successful",
  "rc": 0,
  "stdout": "total 0\ndrwxrwxrwt 1 root root 4096 ...",
  "stderr": ""
}

POST /api/ping

Convenience endpoint to ping a host.

Request Body

Parameter Type Required Description
host string Yes Hostname or IP address to ping
count integer No Number of ping packets (default: 1)

Example Request

curl -X POST http://localhost:8080/api/ping \
  -H "Content-Type: application/json" \
  -d '{
    "host": "127.0.0.1",
    "count": 1
  }'

Response Format

All endpoints return JSON with the following fields:

Field Type Description
status string "successful", "failed", or "timeout"
rc integer Return code from the executed command
stdout string Standard output from the command
stderr string Standard error from the command
