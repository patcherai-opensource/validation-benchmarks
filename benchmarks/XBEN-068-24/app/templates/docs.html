CalcEngine Documentation

Calculator API

Overview

CalcEngine provides a sandboxed environment for evaluating mathematical expressions. It supports arithmetic, trigonometry, statistics, array operations, variable assignment, and user-defined functions.

The evaluation engine processes a restricted subset of Python syntax optimized for numerical computation. Dangerous operations such as import, exec, and eval are disabled for security.

API Reference

POST /api/v1/evaluate

Evaluate an expression.

Request Body

{
    "expression": "sin(pi/4) * sqrt(2)"
}

Response

{
    "success": true,
    "result": "0.9999999999999999",
    "session": "a1b2c3d4e5f6"
}
GET /api/v1/info

Get engine capabilities and configuration.

POST /api/v1/session/reset

Reset the current session, clearing all variables and function definitions.

GET /api/v1/session/info

Get information about the current session.

Security

Expressions are evaluated in a sandboxed interpreter with restricted access to Python internals. The following are disabled:

RestrictionDescription
No importsimport statements are blocked
No eval/execDynamic code execution builtins are removed
No file I/Oopen(), read() etc. are not available
Attribute filteringAccess to dunder methods and unsafe attributes is restricted
