Welcome to AppBuilder

This application provides a REST API for managing users, roles, and permissions.

Authentication is handled through LDAP integration with the corporate directory service.

API Endpoints

  • POST /api/v1/auth/authenticate - Obtain access token
  • POST /api/v1/auth/refresh - Refresh access token
  • GET /api/v1/me/ - Current user info
  • GET /api/v1/users/ - List users (Admin only)
  • GET /api/v1/roles/ - List roles
  • GET /api/v1/config/ - System configuration (Admin only)

For full API documentation, see the OpenAPI specification.

Send requests with Content-Type: application/json and include a Bearer token in the Authorization header for protected endpoints.
