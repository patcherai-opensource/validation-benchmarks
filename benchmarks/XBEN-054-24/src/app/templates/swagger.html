API Documentation

Security

POST /api/v1/security/login

Authenticate and get a JWT access and refresh token

Request Body (application/json)

ParameterTypeRequiredDescription
usernamestringYesThe username for authentication
passwordstringYesThe password for authentication
providerstringYesAuthentication provider (db or ldap)
refreshbooleanNoIf true a refresh token is also provided

Responses

CodeDescription
200Authentication successful. Returns access_token and optionally refresh_token
400Bad request (missing parameters or unsupported provider)
401Unauthorized
POST /api/v1/security/refresh

Use the refresh token to get a new JWT access token

Authorization

Bearer token (refresh token)

Application

GET /api/v1/me/

Get current user information. Requires JWT authentication.

GET /api/v1/users/

List all users. Requires admin role.

GET /api/v1/users/{user_id}

Get a specific user by ID. Requires JWT authentication.

GET /api/v1/roles/

List all roles. Requires JWT authentication.

GET /api/v1/config/

Get application configuration. Requires admin role.
