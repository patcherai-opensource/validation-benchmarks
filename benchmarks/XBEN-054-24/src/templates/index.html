About This Service

This analyzer extracts and displays metadata from PNG image files, including:

  • IHDR - Image dimensions and color type
  • tEXt - Uncompressed text metadata
  • zTXt - Compressed text metadata (zlib deflate)
  • iTXt - International text metadata
  • iCCP - ICC color profile data

Note: Compressed chunks are automatically decompressed for analysis. Large metadata blocks may trigger security warnings.

API Documentation

POST /upload - Upload a PNG file for analysis

curl -X POST -F "image=@photo.png" http://host/upload

POST /api/analyze - Send raw PNG data

curl -X POST -H "Content-Type: image/png" --data-binary @photo.png http://host/api/analyze
