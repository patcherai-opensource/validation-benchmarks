Getting Started

FormBuilder Pro is an advanced form building plugin for WordPress. This documentation covers the main features and usage.

Creating Forms

Navigate to Forms in the dashboard to create and manage your forms. Each form can contain multiple field types including text, email, textarea, and more.

Form Submissions

All form submissions are stored in the database and can be viewed in the dashboard. You can also configure email notifications for new submissions.

Account Settings

Update your email address and other account settings from the Settings page. Form data is passed via hidden form arguments for processing.

Demo Access

For demonstration purposes, a demo account is available. Check the plugin readme for more information about testing.

Technical Notes

Form arguments are serialized and encoded for transmission. The plugin version 1.6.8 uses base64 encoded JSON for form argument passing.
