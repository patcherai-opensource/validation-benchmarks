API Usage Example

List all devices:

curl -H "X-Auth-Token: YOUR_TOKEN" http://host/api/v0/devices

Optional query parameters:

  • order - Field to order results by (e.g., hostname, ip_address, status)
  • type - Filter by device type (e.g., network, firewall, wireless)
