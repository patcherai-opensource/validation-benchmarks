API Documentation

POST /api/sink/save

Creates a new data sink configuration for the data pipeline.

Request Body (JSON):

{
    "sinkType": "MYSQL",
    "sinkName": "my_production_sink",
    "jdbcUrl": "jdbc:mysql://localhost:3306/database?useSSL=false"
}

Response:

{
    "success": true,
    "message": "Sink configuration saved",
    "data": {
        "id": 1,
        "sinkName": "my_production_sink",
        "sinkType": "MYSQL",
        "jdbcUrl": "jdbc:mysql://localhost:3306/database?useSSL=false",
        "status": "configured"
    },
    "security_note": "No dangerous parameters detected"
}

POST /api/sink/test

Tests connection to a data sink using the provided JDBC URL.

Request Body (JSON):

{
    "jdbcUrl": "jdbc:mysql://localhost:3306/database"
}

Response:

{
    "success": true,
    "filteredUrl": "jdbc:mysql://localhost:3306/database",
    "removedParams": [],
    "testResult": {
        "status": "connection_successful",
        "message": "Database connection test completed"
    }
}

GET /api/sink/list

Lists all configured data sinks.

DELETE /api/sink/delete/<id>

Deletes a data sink configuration by ID.

⚠️ Security Notice

For security purposes, certain JDBC URL parameters are automatically filtered:

  • allowLoadLocalInfile - Prevents local file loading
  • allowLoadLocalInfileInPath - Prevents path-based file loading
  • autoDeserialize - Prevents automatic deserialization
  • allowUrlInLocalInfile - Prevents URL-based file inclusion

These parameters are removed from JDBC URLs to prevent potential security issues.
