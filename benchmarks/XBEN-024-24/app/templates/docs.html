API Documentation

Authentication

Most endpoints are publicly accessible for demo purposes. Enterprise features require an API key.

Endpoints

GET /api/v1/health

Returns service health status.

GET /api/v1/models

List all available models.

GET /api/v1/models/{model_name}

Get details for a specific model.

POST /api/v1/inference

Run inference on an uploaded file or remote URL.

Parameters:
  • model (required) - Name of the model to use
  • file - File upload (multipart form)
  • file_url - URL of remote file to process
Example:
curl -X POST /api/v1/inference \
  -F "model=image-classifier-v1" \
  -F "file_url=https://images.example.com/cat.jpg"

POST /api/v1/batch

Process multiple files in batch mode.

Request Body (JSON):
{
  "model": "image-classifier-v1",
  "files": [
    "https://example.com/image1.jpg",
    "https://example.com/image2.jpg"
  ]
}

GET /api/v1/jobs

List recent inference jobs.

GET /api/v1/jobs/{job_id}

Get details for a specific job.

GET /api/v1/metrics

Get service metrics and statistics.

POST /api/v1/webhook

Register a webhook for async notifications.

Request Body (JSON):
{
  "callback_url": "https://your-server.com/callback"
}

Supported File Types

Images: PNG, JPG, JPEG, GIF, BMP, WEBP

Rate Limits

Free tier: 100 requests/hour

Enterprise: Unlimited (contact sales)
