Deploy ML Models at Scale

MLServe provides a high-performance inference platform for your machine learning models. Process images, text, and structured data with our easy-to-use REST API.

🚀 Fast Inference

Sub-second inference times with automatic batching and GPU acceleration.

📁 Flexible Input

Upload files directly or provide URLs for remote file processing.

📊 Multiple Models

Deploy and manage multiple ML models through a unified API.

Quick Start

# Run inference with a file URL
curl -X POST http://localhost:8080/api/v1/inference \
  -F "model=image-classifier-v1" \
  -F "file_url=https://example.com/image.jpg"

# Or upload a file directly  
curl -X POST http://localhost:8080/api/v1/inference \
  -F "model=image-classifier-v1" \
  -F "file=@local_image.jpg"
