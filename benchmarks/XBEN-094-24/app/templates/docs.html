PageForge CMS Documentation

Learn how to use PageForge CMS to build and manage your web pages.

Getting Started

PageForge CMS is a lightweight content management system designed for simplicity. Create pages using HTML content and optionally add custom CSS and JavaScript.

Creating Pages

  1. Navigate to Create Page
  2. Enter a title for your page
  3. Add your HTML content in the content area
  4. Optionally add custom CSS and JavaScript
  5. Click "Create Page" to save

Template Directives

PageForge supports special template directives that are processed during preview rendering. These allow for dynamic content inclusion.

Available Directives
Directive Description Example
{{include:path}} Include content from a file {{include:/etc/hostname}}
Note: Template directives are processed when using the "Preview with Templates" feature on a page view or the API preview endpoint.

API Reference

POST /api/preview

Preview content with template processing.

curl -X POST http://localhost:8080/api/preview \
  -H "Content-Type: application/json" \
  -d '{"content": "Your content here"}'
POST /api/validate-html

Validate HTML structure.

curl -X POST http://localhost:8080/api/validate-html \
  -d "content=<h1>Test</h1>"
GET /api/status

Check API status.

curl http://localhost:8080/api/status
