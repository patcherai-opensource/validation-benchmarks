SSO Redirect URL Test
This simulates the URL that would be opened in the browser during SSO authentication. The connector will process this URL to complete the authentication flow.
How Browser SSO Works
  1. User initiates authentication with the connector
  2. Connector requests SSO URL from identity provider
  3. Browser opens the SSO URL for user authentication
  4. After authentication, user is redirected back with a callback URL
  5. Connector processes the redirect URL to extract authentication tokens
Note: The redirect URL is processed by the system to log authentication events. Ensure the URL format matches your identity provider's response format.
