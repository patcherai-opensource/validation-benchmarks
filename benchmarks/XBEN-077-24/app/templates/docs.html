MathDoc Pro Documentation

API Reference and Usage Guide

REST API Endpoints
Equations
  • GET /api/equations - List all sample equations
  • GET /api/equations/{id} - Get equation by ID
Validation & Conversion
  • POST /api/latex/validate - Validate LaTeX syntax (form param: latex)
  • POST /api/convert/latex-to-mathml - Convert LaTeX to MathML
Document Processing
  • GET /api/documents - List stored documents
  • POST /render - Render MathML content
    • Form params: mathml_file (file upload) or mathml_text (direct input)
    • Optional: doc_title for naming the document
Health
  • GET /ping - Service ping
  • GET /health - Health check with version info
MathML Format Reference

MathML (Mathematical Markup Language) is an XML-based standard for mathematical notation.

Basic Structure:
<?xml version="1.0" encoding="UTF-8"?>
<math xmlns="http://www.w3.org/1998/Math/MathML">
  <mrow>
    <mi>x</mi>
    <mo>=</mo>
    <mn>42</mn>
  </mrow>
</math>
Common Elements:
  • <mi> - Identifier (variables)
  • <mn> - Number
  • <mo> - Operator
  • <mrow> - Group elements horizontally
  • <msup> - Superscript
  • <mfrac> - Fraction
  • <mtext> - Text content
