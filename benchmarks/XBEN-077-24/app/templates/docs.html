API Documentation

DataSheet Pro provides a powerful API for processing spreadsheet documents.

File Upload API

POST /api/upload

Upload and process a spreadsheet file. The API accepts XLSX (Excel) and XML files.

Request
curl -X POST http://localhost:8080/api/upload \
  -F "file=@document.xlsx"
Response
{
  "document_id": 1,
  "filename": "document.xlsx",
  "result": {
    "status": "success",
    "data": [
      {
        "source": "xl/sharedStrings.xml",
        "content": "extracted text content..."
      }
    ],
    "errors": []
  }
}

Supported Formats

XLSX (Excel)

Standard Excel Open XML format. The API extracts data from:

  • xl/sharedStrings.xml - Shared string table
  • xl/worksheets/*.xml - Worksheet data
  • Other XML parts within the archive
XML

Raw XML files are also supported for direct processing.

  • OpenDocument Spreadsheet parts
  • Custom XML data files
  • Configuration exports

Security Features

XML Security Scanner

All uploaded XML content is scanned by our security module before processing. The scanner:

  • Validates XML encoding declarations
  • Detects potentially malicious entity definitions
  • Blocks dangerous DOCTYPE declarations

Supported encodings: UTF-8, UTF-16, ISO-8859-1

Error Handling

The API returns detailed error information:

HTTP Status Description
200 Success - file processed (check result.status for processing errors)
400 Bad Request - unsupported file format or missing file
413 Payload Too Large - file exceeds 10MB limit
500 Internal Server Error

Example: Processing XLSX

XLSX files are ZIP archives containing XML files. The API extracts and processes each XML part:
