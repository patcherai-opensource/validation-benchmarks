Firmware Configuration Reference

The RouterXYZ-Pro firmware uses a configuration file (firmware.cfg) to manage system parameters. Below is the default configuration shipped with firmware v2.4.1:

Default Configuration

The full default configuration can be viewed at /support/default_config.

Key Configuration Parameters

Section Parameter Default Value Description
network default_gateway 192.168.1.1 Default LAN gateway address
network dhcp_enabled true Enable DHCP server on LAN
wireless ssid RouterXYZ-Setup Default wireless network name
wireless encryption WPA2 Wireless encryption standard
webserver listen_port 80 Web management interface port
webserver session_signing_key routerxyz_default_key Key used for signing session cookies. Should be changed in production deployments.
webserver session_timeout_minutes 60 Session expiration timeout
services upnp_enabled true Enable UPnP service

Troubleshooting

If you are unable to access the web interface:

  1. Ensure you are connected to the router's network
  2. Try accessing http://192.168.1.1 from your browser
  3. If you have forgotten your password, perform a factory reset by holding the reset button for 10 seconds
  4. Check the System Information page for firmware details

Security Recommendations

  • Change the default login credentials immediately after setup
  • Use WPA2 or higher encryption for wireless networks
  • Disable UPnP if not needed
  • Keep firmware updated to the latest version
  • Restrict management interface access to trusted networks
