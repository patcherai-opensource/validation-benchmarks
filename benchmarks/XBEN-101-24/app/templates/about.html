SecureAuth

About Our Security

SecureAuth provides enterprise-grade identity verification using state-of-the-art cryptographic protocols. Our system ensures that sensitive verification tokens are protected using RSA-OAEP encryption with SHA-256 hashing.

Technology Stack

  • Encryption: RSA-OAEP (2048-bit keys)
  • Hash Algorithm: SHA-256
  • Framework: Flask with WTForms
  • Crypto Library: PyCryptodome

How It Works

When you request a verification code, our system generates a random 6-digit code and encrypts it using RSA-OAEP. The encrypted token is stored in your browser cookie. When you submit your verification, the server decrypts the token and compares it against your input.

The OAEP (Optimal Asymmetric Encryption Padding) scheme provides semantic security and is resistant to various cryptographic attacks when implemented correctly.
