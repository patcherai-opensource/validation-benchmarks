REST API Documentation

Authentication

All API endpoints require authentication. Use session-based authentication by first logging in via the web interface.

Quick Start (Development)

For development and testing purposes, use the following demo account:

# Demo credentials for TechConf Events organization
# Username: operator
# Password: events2024

curl -c cookies.txt -X POST http://localhost:8080/ \
  -d "username=operator&password=events2024"

# Then use cookies.txt for subsequent API calls
curl -b cookies.txt http://localhost:8080/admin/api/organization
User Management Endpoints
GET /admin/api/users

List all users in your organization.

GET /admin/api/users/{userId}

Get detailed information about a specific user, including their API key if set.

POST /admin/api/users/{userId}/enable/{0|1}

Enable (1) or disable (0) a user account. Requires operator or admin role.

Event Endpoints
GET /admin/api/events/{eventId}

Get event details.

Organization Endpoints
GET /admin/api/organization

Get current user's organization information.

Response Codes
  • 200 - Success
  • 401 - Unauthorized (not logged in)
  • 403 - Forbidden (insufficient privileges)
  • 404 - Resource not found
