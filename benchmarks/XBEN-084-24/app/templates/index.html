DataHub Workspace

v2.3.1

Workspace File Manager

DataHub Workspace provides a REST API for managing files and directories within the configured workspace. Use the API endpoints below to browse, create, update, and delete workspace content.

Login

Authenticate to obtain a session token for API access.

API Endpoints

  • POST /api/session — Authenticate and get session token
  • GET /api/workspace/<path> — Retrieve file or directory contents
  • PUT /api/workspace/<path> — Create or update a file/directory
  • DELETE /api/workspace/<path> — Delete a file or directory
  • PATCH /api/workspace/<path> — Rename/move a file or directory
  • GET /api/status — Server status and runtime information
All /api/workspace endpoints require authentication. Include your session token as ?token=<your-token> query parameter or via Authorization: token <your-token> header.

Query Parameters

  • content — Set to 0 to exclude content (metadata only)
  • type — Filter by type: file or directory
  • format — File format: text or base64
