eZ Platform Installation Guide

This page is a reference for the initial setup of your eZ Platform instance.

System Requirements

  • PHP 7.4+ or Python 2.7+ (for legacy compatibility layer)
  • Database: MySQL 5.7+ or SQLite 3
  • Composer 2.x

Default Accounts

After installation, the following accounts are created:

UsernamePasswordRole
adminPublish2024!Administrator
editorEdit0rPass!Editor

Important: Change these passwords immediately after first login.

Post-Installation Steps

  1. Remove or restrict access to this setup guide
  2. Change default passwords
  3. Configure your web server
